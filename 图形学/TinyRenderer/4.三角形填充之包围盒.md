##### 第二步：判断点是否在三角形中

###### 方法1：利用叉乘计算三角形的有向面积

==<u>重心坐标的概念</u>==

重心坐标的本质是三角形有向面积的比值，而有向面积由叉积/2求得。虽然光栅化中的三角形都没有方向信息，但是由于重心坐标是面积比，所以任意指定三角形为顺时针或逆时针都是可以的。下面的公式延A→B→C方向

$S_{total} = \text{Area}(ABC)$       $S_A = \text{Area}(PBC)$     $S_B = \text{Area}(PCA)$        $S_C = \text{Area}(PAB)$ 

三个重心坐标不可能同时为负，因为重心坐标之和为1

------

AB×AP，BC×BP，CA×CP，本质上是三个三角形的有向面积的两倍，三者只要不是同时为正或为负，相应的重心坐标就一定有负的，点就不在三角形内

```c++
//叉积的计算
int crossproduct(int ax, int ay, int bx, int by, int px, int py)
{
    return (bx - ax) * (py - ay) - (by - ay) * (px - ax);
}

void triangle(int ax, int ay, int bx, int by, int cx, int cy, TGAImage& framebuffer, TGAColor color)
{
    int minx, maxx, miny, maxy;
	minx = std::min(ax, std::min(bx, cx));
	maxx = std::max(ax, std::max(bx, cx));
	miny = std::min(ay, std::min(by, cy));
	maxy = std::max(ay, std::max(by, cy));
    for (int x = minx; x <= maxx; x++)
    {
        for (int y = miny; y <= maxy; y++)
        {
            //如果三个叉积同时为正或同时为负，则在三角形内
            if ((crossproduct(ax, ay, bx, by, x, y) > 0 && crossproduct(bx, by, cx, cy, x, y) > 0 && crossproduct(cx, cy, ax, ay, x, y) > 0)
                || (crossproduct(ax, ay, bx, by, x, y) < 0 && crossproduct(bx, by, cx, cy, x, y) < 0 && crossproduct(cx, cy, ax, ay, x, y) < 0))
            {
                framebuffer.set(x, y, color);
            }
        }
    }
}

```

###### 方法2：利用鞋带公式计算三角形有向面积

鞋带公式本质上也是叉积，其计算结果和叉积的计算结果是完全一样的。但是叉积强调了三角形的==两条边==，而鞋带公式则强调的是==三个点==

```c++
//鞋带公式计算三角形有向面积
double signed_triangle_area(int ax, int ay, int bx, int by, int cx, int cy) {
    return .5 * ((by - ay) * (bx + ax) + (cy - by) * (cx + bx) + (ay - cy) * (ax + cx));
}

void triangle(int ax, int ay, int bx, int by, int cx, int cy, TGAImage& framebuffer, TGAColor color)
{
    int minx, maxx, miny, maxy;
    minx = std::min(ax, std::min(bx, cx));
    maxx = std::max(ax, std::max(bx, cx));
    miny = std::min(ay, std::min(by, cy));
    maxy = std::max(ay, std::max(by, cy));
    //三角形的总面积
    double total_area = signed_triangle_area(ax, ay, bx, by, cx, cy);

    for (int x = minx; x <= maxx; x++) {
        for (int y = miny; y <= maxy; y++) {
			//计算重心坐标
            double alpha = signed_triangle_area(x, y, bx, by, cx, cy) / total_area;
            double beta = signed_triangle_area(x, y, cx, cy, ax, ay) / total_area;
            double gamma = signed_triangle_area(x, y, ax, ay, bx, by) / total_area;
            //重心坐标全为正才说明点在三角形内部
            if (alpha < 0 || beta < 0 || gamma < 0) continue; // negative barycentric coordinate => the pixel is outside the triangle
            framebuffer.set(x, y, color);
        }
    }
}
```

###### 总结对比

| **特性**       | **标准叉乘法**                 | **鞋带公式 / 梯形法**        |
| -------------- | ------------------------------ | ---------------------------- |
| **几何直观**   | 两个向量张成的平行四边形的一半 | 边界投影到坐标轴围成的面积和 |
| **代码结构**   | 针对三个点硬编码               | 适合循环、适合 $n$ 边形      |
| **基准依赖**   | 必须选一个顶点作为原点         | 坐标系无关，平权处理顶点     |
| **计算复杂度** | 略低（减法较少）               | 略高（项数较多）             |
