### 采样方式的优化

##### 最原始的方法

​	输入两个点的坐标，framebuffer和线段的颜色

```c++
void line(int ax, int ay, int bx, int by, TGAImage& framebuffer, TGAColor color)
{
	//通过重心坐标插值的方式来绘制直线，采样比例是0.02
    for (float i = 0; i < 1; i += 0.02)
    {
		int x = round(ax * (1 - i) + bx * i); //round函数用于四舍五入
		int y = round(ay * (1 - i) + by * i);
		framebuffer.set(x, y, color);
    }
}
```

​	假如两个点的x坐标相差很多，而采样数量比这个差值低时，就做不到每个像素点都有采样，就会出现断层的情况。比如下图中的绿色线。

> [!IMPORTANT]
>
> ​	**<u>也就是说，我们不应该手动地去设置采样的次数，而是应该根据两点之间的关系来选择。</u>**

##### 用x坐标来设置采样

```c++
void line(int ax, int ay, int bx, int by, TGAImage& framebuffer, TGAColor color)
{
    //x坐标差值是多少，就采样多少次
    for (int i = ax; i <= bx; i++)
    {
        //t是当前采样点在线段上的比例
        float t = (i - ax) / (float)(bx - ax);
        //用t来求当前的y
        int y = round(ay * (1 - t) + by * t);
        framebuffer.set(i, y, color);
    }
}
```

​	这样写有个问题，如果ax比bx小，则for循环根本不会执行。所以需要加一个判断语句

```c++
void line(int ax, int ay, int bx, int by, TGAImage& framebuffer, TGAColor color)
{
    //如果ax比bx小，那么更换线段的方向，即可让for循环正常进行
    if (ax > bx)
    {
        std::swap(ax, bx);
        std::swap(ay, by);
    }
    for (int i = ax; i <= bx; i++)
    {
        float t = (i - ax) / (float)(bx - ax);
        int y = round(ay * (1 - t) + by * t);
        framebuffer.set(i, y, color);
    }
}
```

​	如果直线很steep，则依据x坐标差值得出的采样率远低于y轴的需求，还是会导致线段上的空洞。

> [!IMPORTANT]
>
> ​	**<u>也就是说，采样率的选择，需要同时兼顾x与y</u>**

##### 考虑直线是否陡峭

```c++
void line(int ax, int ay, int bx, int by, TGAImage& framebuffer, TGAColor color)
{
    //如果直线的角度大于45°，则认为是陡峭的。采用abs绝对值来比较更方便
    bool steep = std::abs(bx - ax) < std::abs(ay - by);
    //如果直线是陡峭的，则交换x坐标和y坐标，便可把直线变得不陡峭，在最后送入framebuffer时再换回来
    if (steep)
    {
        std::swap(ax, ay);
        std::swap(bx, by);
    }
    if (ax > bx)
    {
        std::swap(ax, bx);
        std::swap(ay, by);
    }
    for (int i = ax; i <= bx; i++)
    {
        float t = (i - ax) / (float)(bx - ax);
        int y = round(ay * (1 - t) + by * t);
        //如果直线陡峭，则交换x与y
        if (steep)
        {
            framebuffer.set(y, i, color);
        }
        else
        {
            framebuffer.set(i, y, color);
        }
    }
}
```
