```c++
class Singleton {
public:
    static Singleton& getInstance() {
        static Singleton instance;
        return instance;
    }

    // 禁止拷贝和赋值
    Singleton(const Singleton&) = delete;
    Singleton& operator=(const Singleton&) = delete;

    void doSomething() {
        // 业务逻辑
    }

private:
    Singleton() = default;
    ~Singleton() = default;
};
```

这个类通过 **私有构造函数、局部静态对象、禁止拷贝** 配合实现单例。

1. **私有构造函数，阻止外部直接创建对象**

   ```cpp
   private:
       Singleton() = default;
   ```
   外部不能写 `Singleton s;` 或 `new Singleton;`，只能通过 `getInstance()` 获取对象。

2. **局部 `static` 对象，只初始化一次**

   ```cpp
   static Singleton& getInstance() {
       static Singleton instance;
       return instance;
   }
   ```
   第一次调用时创建 `instance`，后续调用都返回同一个对象。返回类型是 `Singleton&`，因此返回的是原对象的引用，不会产生副本。
   
   从 **C++11 起**，局部静态对象的初始化是线程安全的：多个线程同时首次调用，也只会构造一个对象。不过，这不代表对象的业务方法自动线程安全。
   
3. **删除拷贝构造和赋值，阻止复制**

   ```cpp
   Singleton(const Singleton&) = delete;
   Singleton& operator=(const Singleton&) = delete;
   ```
   其中，删除拷贝构造函数防止通过已有实例创建另一个对象；删除赋值运算符则禁止对象之间赋值。

使用时：
```cpp
auto& a = Singleton::getInstance();
auto& b = Singleton::getInstance();

cout << boolalpha << (&a == &b); // true，同一个对象
```

注意这里的 `auto&` 要保留引用；写成 `auto a = ...` 会尝试拷贝对象，导致编译错误。当前 `main()` 没有调用 `getInstance()`，所以实际上还没有创建这个实例。
