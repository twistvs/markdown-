### 用for循环遍历vector的同时erase偶数

目的：将vector中的偶数删掉

​	如果用erase，每次都会导致右边的所有元素右移，整体复杂度达到O(n2)，而且用for循环的话，每次erase之后，右边的元素下标都会减1，导致漏元素

​	由于不需要保留偶数，所以我们只需要把奇数一个个往前搬就行了

```c++
#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> nums = {2, 4, 5, 6, 8};

    int slow = 0;

    for (int fast = 0; fast < nums.size(); fast++) {
        if (nums[fast] % 2 != 0) {
            nums[slow] = nums[fast];
            slow++;
        }
    }

    // 删除尾部多余元素
    nums.resize(slow);

    for (int num : nums) {
        cout << num << " ";
    }

    return 0;
}
```
