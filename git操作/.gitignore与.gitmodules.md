### .gitignore

.gitignore用来指定哪些文件/文件夹不需要被git跟踪

常见用途是忽略：

```
# 编译生成文件
build/
dist/
*.o
*.exe

# IDE 配置
.vscode/
.idea/

# 日志文件
*.log

# 临时文件
*.tmp

# 依赖目录
node_modules/

# 系统文件
.DS_Store
Thumbs.db
```

### .gitmodules

`.gitmodules` 用来记录项目中使用的 **Git Submodule 子模块**。

子模块就是：一个 Git 仓库里面嵌套另一个 Git 仓库。

例如你的项目依赖一个第三方库：

```
MyProject/
├── src/
├── CMakeLists.txt
├── third_party/
│   └── glfw/        ← 这是另一个 Git 仓库
└── .gitmodules
```

这时 `.gitmodules` 可能长这样：

```
[submodule "third_party/glfw"]
    path = third_party/glfw
    url = https://github.com/glfw/glfw.git
```

它记录了：

```
子模块路径：third_party/glfw
子模块地址：https://github.com/glfw/glfw.git
```

当别人克隆你的项目时，如果项目用了子模块，需要这样拉取：

```
git clone --recursive <你的仓库地址>
```

或者已经克隆了项目，再执行：

```
git submodule update --init --recursive
```

否则 `third_party/glfw` 目录可能是空的，或者只有一个指向特定提交的引用。
