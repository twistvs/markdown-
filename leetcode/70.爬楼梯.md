#### 最简单的动态规划

​	dp[i]是爬到第i个台阶时有多少中不同的方法，他等于dp[i - 1] + dp[i - 2]，他有两种不同的路径可以到达第i阶，两种路径的数量相加，就是dp[i]

```c++
class Solution {
public:
    int climbStairs(int n) {
        if(n == 1) return 1;
        vector<int> dp(n + 1);

        dp[0] = 1;
        dp[1] = 1;

        for(int i = 2; i <= n; i++){
            dp[i] = dp[i - 1] + dp[i - 2];
        }

        return dp[n];
    }
};
```
