本质上是**动态规划**的一种，因为第i天能获得的最大利润只和前i-1的最低价有关

如果我们算出每一天的最大利润，然后在其中取最大值，就可以得到利润最高的那一天



可以用dp来写，但是这道题有一种更简答的写法：
用low实时记录最小的值，再用当天的价格减去low获取“当天可以获得的最大值（也就是当天的价格减去前面的最小值”），然后再全局维护一个max，如果当天的最大值比max更大，则更新max。
这个方法看起来并没有用到dp，但是思想和dp是完全一致的，都是通过比较每一天可以获得的最大利润和得到最大利润最大的那一天

```c++
class Solution {
public:
    int maxProfit(vector<int>& prices) {
        int n = prices.size();

        int low = prices[0];

        int max = 0;

        for(int price : prices){
            if(price < low){
                low = price;
            }

            if(price - low > max){
                max = price - low;
            }
        }

        return max;
    }
};
```
