**滑动窗口**

​	**子序列**是不连续的，一般用双指针；**子数组**是连续的，一般用滑动窗口

​	滑动窗口的一个关键是窗口的边界应该怎么动，谁先动谁后动

​	这道题是遍历右边界，右边界走一步，左边界可能不走，也可能走好几步，总之需要走到sum<target为止

```c++
class Solution {
public:
    int minSubArrayLen(int target, vector<int>& nums) {
        int n = nums.size();
        int left = 0;
        int right = 0;

        int sum = 0;

        int minLen = INT_MAX;

        for(right = 0; right < n; right++){
            sum += nums[right];

            while(sum >= target){
                minLen = min(minLen, right - left + 1);
                sum -= nums[left];
                left++;
            }
        }

        return minLen == INT_MAX ? 0 : minLen;
    }
};
```
