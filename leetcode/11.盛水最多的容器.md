#### 特殊解法题

- 先令左边界为0，右边界为n - 1；此时选择一个边界往里面缩

1. 如果让更长的那一边往里缩，那么底边一定会缩短的同时，高也一定不会上升（因为如果新的边比短边长，也是取短边），所以面积只可能会下降，没有意义
2. 从短边的角度来讲，他和1, 2, 3, ....., n-2组成的面积一定不会大于n - 1，也就是说短边能提供的最大面积我们已经获得了，他就没有作用了，所以直接抛弃短边，将短边往里面缩

```c++
class Solution {
public:
    int maxArea(vector<int>& height) {
        int n = height.size();
        int left = 0;
        int right = n - 1;

        int ans = 0;

        while(left < right){
            int s = min(height[right], height[left]) * (right - left);
            ans = max(ans, s);
            if(height[left] <= height[right]){
                left++;
            }
            else{
                right--;
            }
        }
        return ans;
    }
};
```

**双指针题，关键在于他的思路比较骚**

​	对于接雨水来说，每个位置的接水量由他左最高水位和右最高水位的较小值决定；而对于盛水容器来说，每种情况（指的是左边界和右边界的位置）的接水量由左边界和右边界的较小值和底差值的乘积决定

​	边界还是从最左和最右开始，==更矮的那一边往里挪==，因为如果挪更高的，底边长一定会缩短，而四边形的高也只可能会缩短（因为被更矮的那个边给限制住了），也就是说，如果想要在往里缩的过程中让面积变大，只能挪更矮的那一边（虽然也不是百分百会变大，但是只有这样操作才有可能变大）

```c++
class Solution {
public:
    int maxArea(vector<int>& height) {
        int n = height.size();

        int left = 0;
        int right = n - 1;

        int ans = 0;

        while(left < right){
            int s = (min(height[left], height[right]))*(right - left);

            ans = max(ans, s);

            if(height[left] <= height[right]){
                left++;
            }
            else{
                right--;
            }
        }

        return ans;

    }
};
```
