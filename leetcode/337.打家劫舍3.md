#### 打家劫舍的二叉树版本

- 二叉树版本的打家劫舍需要用两个状态dp来分别记录偷node和不偷node的状态

- steel和noSteel都没有进行初始化，是因为当node为NULL时，val默认就是0，不需要再初始化

```c++
class Solution {
public:
    unordered_map<TreeNode*, int> steel, noSteel;

    void dfs(TreeNode* root){
        if(root == NULL){
            return;
        }

        dfs(root->left);
        dfs(root->right);

        //如果偷了root，则左右子树都不能偷
        steel[root] = root->val + noSteel[root->left] + noSteel[root->right];
        //如果没偷root，则左右子树可偷可不偷，取最大的情况
        noSteel[root] = max(steel[root->left], noSteel[root->left]) + max(steel[root->right], noSteel[root->right]);
    }

    int rob(TreeNode* root) {
        dfs(root);
        return max(steel[root], noSteel[root]);
    }
};
```

#### 二刷新解

​	第一次写的时候是个菜逼，遇到这种返回值比较复杂的dfs就懵逼了，只好借助一个全局哈希表来把所有节点的值都存起来，但是这样很明显会浪费空间，完全可以用dfs的返回值把值一步步往上传

```c++
class Solution {
public:
    pair<int, int> dfs(TreeNode* root){
        if(!root){
            return {0, 0};
        }

        pair<int, int> left = dfs(root->left);
        pair<int, int> right = dfs(root->right);

        int pick = left.second + right.second + root->val;
        int noPick = max(left.first, left.second) + max(right.first, right.second);

        //向上传的是选root和不选root的两种最大值
        return {pick, noPick};
    }

    int rob(TreeNode* root) {
        
        pair<int, int> ans = dfs(root);

        return max(ans.first, ans.second);
    }
};
```
