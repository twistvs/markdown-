#### 简单方法：两层遍历

​	这道题并不能先排序然后用双指针，因为返回的答案是数组下标，如果先排序，下标就乱了

```c++
class Solution {
public:
    vector<int> twoSum(vector<int>& nums, int target) {
        int n = nums.size();


        for(int i = 0; i < n; i++){
            for(int j = i + 1; j < n;j++){
                if(nums[i] + nums[j] == target){
                    return {i, j};
                }
            }
        }

        return {};
    }
};
```

#### **对于两数和来讲很好用的方法：用哈希表记录差值**

​	已经遍历到的数组存进哈希表，他作为target-nums[i]来使用

```c++
class Solution {
public:
    vector<int> twoSum(vector<int>& nums, int target) {
        unordered_map<int, int> m;

        int n = nums.size();

        for(int i = 0; i < n; i++){
            if(m.count(target - nums[i])){
                return {m[target - nums[i]], i};
            }
            m[nums[i]] = i;
        }

        return {};
    }
};
```
