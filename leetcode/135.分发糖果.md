#### 两次遍历



**哪里贪心了？**

贪心不一定非得是取最大值，贪最小的也是一种贪心



**双向贪心**

如果把问题改一下，改成：只有右边的孩子分数比左边的高时，右边的才会获得更多糖果，那么就只需要保证每个右边的孩子比左边的多1个糖果，就可以实现整体最优



```c++
class Solution {
public:
    int candy(vector<int>& ratings) {
        int n = ratings.size();

        //每个人最少一个糖果
        vector<int> candyNum(n, 1);

        //从左往右遍历
        for(int i = 1; i < n; i++){
            if(ratings[i] > ratings[i - 1]){
                candyNum[i] = max(candyNum[i], candyNum[i - 1] + 1);
            }
        }

        //从右往左遍历
        for(int i = n - 2; i >= 0; i--){
            if(ratings[i] > ratings[i + 1]){
                //注意取最大值
                candyNum[i] = max(candyNum[i], candyNum[i + 1] + 1);
            }
        }

        int sum = 0;

        for(int i : candyNum){
            sum += i;
        }
        return sum;
    }
};
```
