只需要维护不等于val的所有元素，等于val的所有元素不需要被维护，所以可以直接将不等于val的元素往左覆盖

当right不等于val时就往左覆盖，并且将left++，当right遍历完时，left正好处在下标为k的位置

> [!NOTE]
>
> left和right都从0开始
> right自己动，left只在right不等于val，进行覆盖之后动

```c++
class Solution {
public:
    int removeElement(vector<int>& nums, int val) {
        int n = nums.size();

        int left = 0;

        for(int right = 0; right < n; right++){
            if(nums[right] != val){
                nums[left] = nums[right];
                left++;
            }
        }

        return left;
    }
};
```
