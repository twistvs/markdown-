#### 两棵树的dfs，关键在于什么情况属于终点状态

​	root1 == nullptr是终点状态吗？root2 == nullptr是终点状态吗？还是说只有两个都是nullptr的时候才是终点状态

​	答案是，都算终点状态，因为只要有一个root是空，那么两颗树就不需要合并了，直接跳过了递归中的操作步骤，直接把不是空的那颗树返回就行了

```c++
class Solution {
public:
    TreeNode* mergeTrees(TreeNode* root1, TreeNode* root2) {
        //终点状态
        if (root1 && !root2) {
            return root1;
        }
        if (root2 && !root1) {
            return root2;
        }
        if (!root1 && !root2) {
            return nullptr;
        }
		
        root1->val += root2->val;
        root1->left = mergeTrees(root1->left, root2->left);
        root1->right = mergeTrees(root1->right, root2->right);
        return root1;
    }
};
```
