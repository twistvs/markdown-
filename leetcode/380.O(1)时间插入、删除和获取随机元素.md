#### vector实现O(1)随机访问，map实现O(1)插入删除



**随机访问**

​	有一个vector v，那么rand() % v.size()就可以随机获取vector的一个下标，实现随机访问；

​	map这种哈希表无法实现随机访问，因为key的实际内容不可随机获取



O(1)**的插入删除**

​	众所周知，只有哈希表可以实现O(1)的插入删除，但是哈希表又不能实现随机存储，所以我们选择把vector和哈希表组合起来，用哈希表存储<val, index>，通过哈希表来索引vector的内容，就可以实现O(1)的插入删除

```c++
class RandomizedSet {
public:
    RandomizedSet() {
    }
    
    //插入很简单
    bool insert(int val) {
        if(index.count(val) == 0){
            value.push_back(val);
            index[val] = value.size() - 1;
            return true;
        }
        else{
            return false;
        }
    }
    
    //我们不能使用erase来删除vector中的元素，因为这样会导致后面的元素左移，时间复杂度很高
    //而且元素左移会导致map中的所有索引都要改，非常麻烦
    //我们将需要删除的元素换到队尾，用pop_back来删除他，不要忘了把被换走的队尾元素的索引进行更新
    bool remove(int val) {
        if(index.count(val) == 0){
            return false;
        }
        else{
            int delIndex = index[val];
            value[delIndex] = value.back();
            index[value.back()] = delIndex;
            value.pop_back();
            index.erase(val);
            return true;
        }
    }
    
    int getRandom() {
        //vector可以通过这种方式实现随机访问
        int randomIndex = rand()%value.size();
        return value[randomIndex];
    }

private:
    //为了使随机访问的时间复杂度达到O(1)，需要用到vector；vector用于存储数据
    vector<int> value;

    //为了使插入删除的时间复杂度达到O(1)，需要用到map；map用于存储值和vector下标的映射
    unordered_map<int, int> index;
};
```
