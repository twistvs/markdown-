## 一、最常用的 C++ 头文件

| 头文件            | 主要功能       | 常用内容                        |
| ----------------- | -------------- | ------------------------------- |
| `<iostream>`      | 输入输出       | `cin`、`cout`                   |
| `<vector>`        | 动态数组       | `vector`                        |
| `<string>`        | 字符串处理     | `string`、`stoi`、`to_string`   |
| `<algorithm>`     | 常用算法       | `sort`、`reverse`、`max`、`min` |
| `<unordered_map>` | 哈希表         | `unordered_map`                 |
| `<unordered_set>` | 哈希集合       | `unordered_set`                 |
| `<map>`           | 有序映射       | `map`                           |
| `<set>`           | 有序集合       | `set`                           |
| `<queue>`         | 队列、优先队列 | `queue`、`priority_queue`       |
| `<stack>`         | 栈             | `stack`                         |
| `<deque>`         | 双端队列       | `deque`                         |
| `<numeric>`       | 数学与数值算法 | `accumulate`、`gcd`、`iota`     |
| `<cmath>`         | 数学函数       | `sqrt`、`pow`、`ceil`、`floor`  |
| `<climits>`       | 整数边界       | `INT_MAX`、`INT_MIN`            |
| `<cctype>`        | 字符判断与转换 | `isdigit`、`isalpha`、`tolower` |
| `<sstream>`       | 字符串流       | `stringstream`                  |
