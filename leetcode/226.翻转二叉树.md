#### DFS

**处理root的timing**

​	需要先把左子树翻转，再把右子树翻转，再将root的左右孩子交换，所以是后序遍历

**返回timing**

​	当root ==nullptr，返回nullptr

```c++
class Solution {
public:
    TreeNode* invertTree(TreeNode* root) {
        if(root == NULL){
            return NULL;
        }
		
        //对于叶子节点，他的左儿子和右儿子都是NULL
        TreeNode* left = invertTree(root->left);
        TreeNode* right = invertTree(root->right);

        root->left = right;
        root->right = left;

        return root;
    }
};
```
