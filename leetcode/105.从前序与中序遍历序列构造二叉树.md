#### 递归

- 递归构造二叉树，最外层是包含所有结点，下一层是包含左子树的所有结点和右子树的所有结点，最后一层是叶子结点，每一层递归的关键是找到当前递归的子树包含哪些结点

- 对于一棵树来讲，他的根结点是前序遍历的第一个结点
- 左子树和右子树包含的结点范围如图所示
- 为了通过root的值找到root在中序遍历中的位置，需要用map来创造映射

```c++
class Solution {
public:
    //用来存储中序遍历中元素对应的序号,<元素,对应的序号>
    unordered_map<int, int> pos;

    //递归的是结点的范围，对于最外层的递归，当然要包括所有结点，每一层递归都是一个左子树或者一个右子树，把他们当成一棵树来做构造，最终递归到最里层，也就是一个结点构成的树
    TreeNode* build(vector<int>& preorder, vector<int>& inorder, int pre_left, int pre_right, int in_left, int in_right){
        //如果pre_left大于pre_right，就说明要构造的序列里面根本没有值，也就不需要构造了
        if(pre_left > pre_right){
            return NULL;
        }

        //要构造的序列的前序遍历的第一个值肯定是根节点
        int root_val = preorder[pre_left];
        TreeNode* root = new TreeNode(root_val);

        //在中序遍历中，root的左边全部都是左子树的结点，所以左子树的结点数量可以这样计算
        int root_in_index = pos[root->val];
        int left_size = root_in_index - in_left;

        //左子树的结点在前序遍历中是根节点右边部分的左半部分，在中序遍历中是根节点的左边的部分，结点数量为left_size
        root->left = build(preorder, inorder, pre_left + 1, pre_left + left_size, in_left, root_in_index - 1);

        //右子树的结点在前序遍历中根节点右边部分的右半部分，在中序遍历中是根节点的右边的部分
        root->right = build(preorder, inorder, pre_left + left_size + 1, pre_right, root_in_index + 1, in_right);

        return root;
    }
    
    TreeNode* buildTree(vector<int>& preorder, vector<int>& inorder) {
        int n = inorder.size();
        for(int i = 0; i < n; i++){
            pos[inorder[i]] = i;
        }
        //最外层包含所有结点
        return build(preorder, inorder, 0, n - 1, 0, n - 1);
    }
};
```

#### <二刷>新的思路梳理

​	对于想要构造一棵树，可以先构造左子树，再构造右子树，然后把根节点和左右子树连起来，而这里的递归思路就是这样的

==这道题并不是常见的在树里面递归，而是在两个数组里面递归，那么我们该如何构建递归的框架？==

​	**先序遍历+中序遍历=树**

关键中的关键就在于这里，两个数组和一棵树是可以**一一对应**的，数组本身就是树，所以我们在遍历数组的过程中，就是在遍历树

```c++
class Solution {
public:
    //通过preL,preR,inL,inR我们可以将preorder和inorder动态地切割成不同的数组，我们并不需要真的对这两个数组进行操作，只需要记录他们的边界即可
    TreeNode* build(vector<int>& preorder, vector<int>& inorder, int preL, int preR, int inL, int inR){
        //遍历到空节点时，preL会大于preR
        if(preL > preR){
            return nullptr;
        }
        
        //先序遍历的第一个节点是根节点
		//用inL_temp作为标记，用他标记inorder中，根节点的位置
        int leftLen = 0;
        int inL_temp = inL;
        while(inorder[inL_temp] != preorder[preL]){
            inL_temp++;
            leftLen++;
        }

        //切割左子树数组和右子树数组，构造左子树和右子树
        TreeNode* leftNode = build(preorder, inorder, preL + 1, preL + leftLen, inL, inL_temp - 1);
        TreeNode* rightNode = build(preorder, inorder, preL + leftLen + 1, preR, inL_temp + 1, inR);

        //创建根节点，并且将他和左右子树连接起来
        TreeNode* ans = new TreeNode(preorder[preL]);
        ans->left = leftNode;
        ans->right = rightNode;
        return ans;
    }

    TreeNode* buildTree(vector<int>& preorder, vector<int>& inorder) {
        int n = preorder.size();

        return build(preorder, inorder, 0, n - 1, 0, n - 1);
    }
};
```

**优化**

​	在寻找inorder的根节点位置时，需要用循环，如果根节点在inorder的最右边，就会导致循环的复杂度很高。

为了跳过寻找根节点的步骤，我们可以提前将inorder的值->索引的映射记录在unordered_map中

```c++
class Solution {
public:
    TreeNode* build(vector<int>& preorder, vector<int>& inorder, int preL, int preR, int inL, int inR){
        if(preL > preR){
            return nullptr;
        }

        //通过哈希表直接获得根节点在inorder中的索引
        int rootInorderIndex = inorderIndex[preorder[preL]];
        int leftLen = rootInorderIndex - inL;

        TreeNode* leftNode = build(preorder, inorder, preL + 1, preL + leftLen, inL, rootInorderIndex - 1);
        TreeNode* rightNode = build(preorder, inorder, preL + leftLen + 1, preR, rootInorderIndex + 1, inR);

        TreeNode* ans = new TreeNode(preorder[preL]);
        ans->left = leftNode;
        ans->right = rightNode;
        return ans;
    }

    TreeNode* buildTree(vector<int>& preorder, vector<int>& inorder) {
        int n = preorder.size();

        for(int i = 0; i < n; i++){
            inorderIndex[inorder[i]] = i;
        }

        return build(preorder, inorder, 0, n - 1, 0, n - 1);
    }

private:
    unordered_map<int, int> inorderIndex;
};
```
