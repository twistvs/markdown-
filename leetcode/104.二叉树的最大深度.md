#### 二叉树的基础

**前序遍历，中序遍历，后序遍历到底有什么区别？**

​	三种遍历都是**深度优先搜索DFS**，==三者的区别是对root的处理timing不一样==

```c++
void dfs(TreeNode* root) {
    if (!root) return;

    // 位置 1：前序位置

    dfs(root->left);

    // 位置 2：中序位置

    dfs(root->right);

    // 位置 3：后序位置
}
```

**这道题的处理timing在哪里？**

​	一个节点的最大深度 = max(左子树的最大深度，右子树的最大深度) + 1。很明显root的处理在左子树和右子树之后，也就是后序遍历

**怎么处理返回timing？**

​	当深度搜索到nullptr时，返回0，这样就可以得到叶子节点的深度为1，符合实际情况

```c++
class Solution {
public:
    int maxDepth(TreeNode* root) {
        if(root == nullptr){
            return 0;
        }

        int leftDepth = maxDepth(root->left);
        int rightDepth = maxDepth(root->right);

        return max(leftDepth, rightDepth) + 1;
    }
};
```
