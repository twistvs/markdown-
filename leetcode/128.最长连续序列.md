#### 哈希表

这个题有一个很阴的点，**子序列**是要求保持原数组中的顺序的，但是这道题要求的**序列**并不需要保持原有顺序

把nums存入哈希表set，有两个作用：

1. 由于重复数字在这里只有干扰作用，所以set可以帮助自动剔除重复数字
2. set的查找效率极高，时间复杂度为O(1)，在确定一个序列的第一个数字后，就可以一个个把后面的所有数字查找出来

```c++
class Solution {
public:
    int longestConsecutive(vector<int>& nums) {
        int n = nums.size();
        //把nums存入哈希表
        unordered_set<int> hash(nums.begin(), nums.end());
        int ans = 0;
        int length = 0;

        //遍历set中的元素，如果该元素-1在set中不存在，说明该元素是一个序列的开头
        for(int num : hash){
            if(hash.count(num - 1) == 0){
                int curr = num;
                length = 1;
                //逐个遍历序列后面的元素，直到他不在set中存在为止，这样就可以得到一个子序列
                while(hash.count(curr + 1)){
                    curr++;
                    length++;
                }
            }
            ans = max(ans, length);
        }
        return ans;
    }
};
```

#### 二刷总结

​	对于数组题来说，判断结果是否需要连续和是否需要维持原顺序是很关键的。

​	如果是子序列需要维持原顺序，就不能对数组排序

​	如果是字串，就既不能用set去重，也不能对数组排序



​	对于这道题来讲，没有任何限制，我们可以用unordered_set去重，然后利用count达到O(1)查找

```c++
class Solution {
public:
    int longestConsecutive(vector<int>& nums) {
        unordered_set<int> s(nums.begin(), nums.end());

        int ans = 0;

        for(int num : s){
            int cur = num;
            int len = 1;

            //如果比num小1的数存在，那么num就肯定不是一个连续序列的开头
            if(s.count(cur - 1)){
                ans = max(ans, len);
                continue;
            }

            while(s.count(cur + 1)){
                cur++;
                len++;
            }
            ans = max(ans, len);
        }

        return ans;
    }
};
```
