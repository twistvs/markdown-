多次买卖，最多持一股



也是动态规划，第i天的最大利润等于max(前一天不持有的最大利润dpn[i - 1]，前一天持有的最大利润dpy[i - 1] + 第i天的价格prices[i])

需要维护两个数组dpn和dpy分别表示持有状态和非持有状态

```c++
class Solution {
public:
    int maxProfit(vector<int>& prices) {
        int n = prices.size();

        vector<int> dpn(n + 1);
        vector<int> dpy(n + 1);

        dpn[1] = 0;
        dpy[1] = -prices[0];

        for (int i = 2; i <= n; i++) {
            dpn[i] = max(
                dpn[i - 1],
                dpy[i - 1] + prices[i - 1]
            );

            dpy[i] = max(
                dpy[i - 1],
                dpn[i - 1] - prices[i - 1]
            );
        }

        return dpn[n];
    }
};
```
