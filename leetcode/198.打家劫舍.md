#### 动态规划

**dp[i]表示0到i元素能偷的最大数额**

- 如果偷i，i - 1就不能偷，`dp[i] = nums[i] + dp[i - 2]`
- 如果不偷i，i -1 就可以偷`，dp[i] = dp[i - 1]`

**边界条件**

由于公式里面有dp[i - 2]，为了避免索引溢出，需要提前处理dp[0]和dp[1]，并且使循环从dp[2]开始



```c++
class Solution {
public:
    int rob(vector<int>& nums) {
        int n = nums.size();
        int ans = 0;
        if(nums.empty()){
            return 0;
        }
        if(nums.size() == 1){
            return nums[0];
        }
        vector<int> dp(n, 0);
        dp[0] = nums[0];
        dp[1] = max(nums[0], nums[1]);
        ans = dp[1];


        //由于公式里面有dp[i - 2]，所以i只能从2开始
        for(int i = 2; i < n; i++){
            dp[i] = max(nums[i] + dp[i - 2], dp[i - 1]);
            ans = max(ans, dp[i]);
        }
        return ans;
    }
};
```

#### 优化过的写法

**为什么答案一定是dp[n]而不是其他的？**

​	因为如果倒数第二个是10000000，那么dp[n]就会等于dp[i - 1]，也就是和倒数第二个一样，也就是说在遍历的过程中，dp[大]不可能比dp[小]更小

```c++
class Solution {
public:
    int rob(vector<int>& nums) {
        int n = nums.size();

        vector<int> dp(n + 1);

        dp[0] = 0;

        for(int i = 1; i <= n; i++){
            if(i == 1){
                dp[i] = nums[0];
            }
            else{
                dp[i] = max(dp[i - 2] + nums[i - 1], dp[i - 1]);
            }
        }

        return dp[n];
    }
};
```
