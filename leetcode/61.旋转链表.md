#### 很抽象的题

​	先把链表的头尾连起来变成衔尾蛇，然后再找到对应的地方断掉，就变成了一个新的链表

```c++
class Solution {
public:
    ListNode* rotateRight(ListNode* head, int k) {
        if(!head || !head->next){
            return head;
        }

        int len = 1;

        ListNode* temp = head;
		
        //计算链表的长度，把链表的头尾连起来
        while(temp->next){
            len++;
            temp = temp->next;
        }
        temp->next = head;

        int k2 = k % len;

        //定位断开的点，断开链表，然后将新的头节点返回
        temp = head;
        for(int i = 0; i < len - k2 - 1; i++){
            temp = temp->next;
        }
        ListNode* ans = temp->next;
        temp->next = nullptr;

        return ans;
    }
};
```
