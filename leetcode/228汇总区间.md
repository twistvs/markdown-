#### 怎样才能避免各种边界条件

1. 从一个序列进入下一个序列的标志是right，right要发现一次元素的跳变，而如果我们用`nums[right] != nums[right - 1] + 1`来判断序列的切换，会导致最后一次序列切换被漏掉的问题（最后一个序列结束时也要进行一次结算，就相当于一次切换），所以我们不能用`nums[right] != nums[right - 1] + 1`，而是需要用`nums[right] != nums[right + 1] - 1`来判断序列的切换
2. 由于right在进行序列切换时处于上一个序列的末尾，此时left会被设置为right+1，出现“left跑到right后面”的情况，这种情况就不适合用right做主导，而是更适合用left做主导，left先动，right再动（动一次或者动多次）

```c++
class Solution {
public:
    vector<string> summaryRanges(vector<int>& nums) {
        vector<string> ans;

        int n = nums.size();
        int start = 0;

        while (start < n) {
            int end = start;

            while (end + 1 < n &&
                   nums[end + 1] == nums[end] + 1) {
                ++end;
            }

            if (start == end) {
                ans.push_back(to_string(nums[start]));
            }
            else {
                ans.push_back(
                    to_string(nums[start]) +
                    "->" +
                    to_string(nums[end])
                );
            }

            start = end + 1;
        }

        return ans;
    }
};
```
