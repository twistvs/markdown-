#### 怪特殊的

​	由于两个分区的节点顺序是要保留的，所以需要顺着遍历一个个摘出来

​	新开两个链表，遍历原链表，比x小的插small后面，比x大的插big后面，最后再把small的尾巴接到big的头上就可以了

```c++
class Solution {
public:
    ListNode* partition(ListNode* head, int x) {
        if(!head || !head->next){
            return head;
        }

        ListNode* smallDummy = new ListNode(0);
        ListNode* bigDummy = new ListNode(0);

        ListNode* smallcurr = smallDummy;
        ListNode* bigcurr = bigDummy;

        ListNode* curr = head;

        while(curr){
            if(curr->val < x){
                smallcurr->next = curr;
                smallcurr = smallcurr->next;
            }
            else{
                bigcurr->next = curr;
                bigcurr = bigcurr->next;
            }
            curr = curr->next;
        }

        bigcurr->next = nullptr;
        smallcurr->next = bigDummy->next;

        return smallDummy->next;
    }
};
```
