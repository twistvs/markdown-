**哈希表**

​	**字母异位词**非常适合用计数数组来做，建立一个容量为26的vector，先用s加，再用t减，结果要全部等于0，就说明他们是字母异位词

```c++
class Solution {
public:
    bool isAnagram(string s, string t) {
        int sLen = s.size();
        int tLen = t.size();

        vector<int> count(26, 0);

        for(int i = 0; i < sLen; i++){
            count[s[i] - 'a']++;
        }

        for(int i = 0; i < tLen; i++){
            count[t[i] - 'a']--;
        }

        for(int num : count){
            if(num){
                return false;
            }
        }

        return true;
    }
};
```
