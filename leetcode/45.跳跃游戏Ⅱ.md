#### 贪心（难）



**本质上是贪心**

​	这个题虽然看起来不太像贪心，但是实际上还是贪心，我们关心的是“这一跳的范围内可以到达的最远的下一跳的范围”，本质上还是在求最大的范围



**有点像二叉树的层次遍历BFS**

​	第一层是第一个元素，第二层是第一个元素能够跳到的范围，第三层是上一个范围内的所有元素最远能够跳到的范围

比如对于[2,3,1,1,4]

| [2]   |
| ----- |
| [3,1] |
| [1,4] |
|       |

一层=一跳，在遍历的过程中，每当到达了一层的边界，就要增加一跳

```c++
class Solution {
public:
    int jump(vector<int>& nums) {
        if (nums.size() <= 1) return 0;

        int steps = 0;          // 跳跃次数
        int curDistance = 0;    // 当前跳跃覆盖的最远距离下标
        int nextDistance = 0;   // 下一步跳跃能覆盖的最远距离下标

        // 注意：遍历范围是 0 到 n-2
        // 因为如果当前已经覆盖了最后一个元素，就不需要再多跳一次了
        for (int i = 0; i < nums.size() - 1; i++) {
            // 更新下一步能跳的最远位置
            nextDistance = max(nextDistance, i + nums[i]);

            // 当走到当前这一跳的“极限”时
            if (i == curDistance) {
                steps++;                // 必须跳一次
                curDistance = nextDistance; // 更新当前边界
                
                // 如果当前边界已经覆盖终点，可以提前跳出
                if (curDistance >= nums.size() - 1) break;
            }
        }
        return steps;
    }
};
```
