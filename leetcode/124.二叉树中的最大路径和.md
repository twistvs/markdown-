#### dfs

​	我们再回顾一下dfs四要素：

1. 我应该返回什么？
2. root==nullptr时怎么处理？
3. 在什么时候处理root？
4. 该怎么处理root？

​	答：

1. 应该返回经过自己的最长的带权深度
2. 返回0
3. 在获得左子树的最长带权深度和右子树的最长带权深度后（后序）
4. 计算经过root的最长路径，并且和ans作比较

```c++
class Solution {
public:
    int dfs(TreeNode* root){
        //处理nullptr
        if(root == nullptr){
            return 0;
        }

        int leftDepth = dfs(root->left);
        int rightDepth = dfs(root->right);

        //操作部分
        int maxLen = root->val;
        if(leftDepth > 0) maxLen += leftDepth;
        if(rightDepth > 0) maxLen += rightDepth;
        ans = max(ans, maxLen);

        //返回经过自己的最长带权深度
        return max(leftDepth + root->val, max(rightDepth + root->val, root->val));
    }

    int maxPathSum(TreeNode* root) {
        dfs(root);
        return ans;
    }

private:
    int ans = INT_MIN;
};
```
