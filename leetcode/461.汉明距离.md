#### 位处理

​	十进制数转二进制数的算法	

​	需要注意，如果a已经除到0了，但是b还没除到0，那么还要继续把b除完，后面b余1的时候就和a不一样

```c++
class Solution {
public:
    int hammingDistance(int x, int y) {
        int res_x = 0;
        int res_y = 0;

        int ans = 0;

        while(x || y){
            res_x = x % 2;
            res_y = y % 2;
            if(res_x != res_y){
                ans++;
            }

            x = x / 2;
            y = y / 2;
        }

        return ans;
    }
};
```
