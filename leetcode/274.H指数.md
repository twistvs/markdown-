排序后，至少有1篇论文被引用了citations[n - 1]次，至少有2篇论文被引用了citations[n - 2]次，这样一来，每个元素的篇数和引用数都有了，就可以一个个作比较了

```
6   -> 至少有 1 篇引用 >= 1
5   -> 至少有 2 篇引用 >= 2
3   -> 至少有 3 篇引用 >= 3
1   -> 至少有 4 篇引用 >= 4  ❌

至少有x篇被引用y次，总是取最小的那个，然后每个遍历得到的那个较小值再取最大的
```

```c++
class Solution {
public:
    int hIndex(vector<int>& citations) {
        int n = citations.size();
        int h = 0;

        int count = 0;

        //排序后，至少有1篇论文被引用了citations[n - 1]次，至少有2篇论文被引用了citations[n - 2]次
        sort(citations.begin(), citations.end());

        for(int i = n - 1; i >= 0; i--){
            count++;
            int temp = min(count, citations[i]);
            h = max(h, min(n, temp));
        }

        return h;
    }
};
```
