**非常抽象的题**

​	乍一看还以为要通过逻辑来判断罗马数字的前后顺序，比如51是LI，49是IL，结果是他妈的靠硬编码把所有的组合情况列出来，然后用贪心从左到右拼



**贪心**

​	每一次都选择满足条件的最大的那个罗马数字



```c++
class Solution {
public:
    string intToRoman(int num) {
        const pair<int, string> valueSymbols[] = {
            {1000, "M"}, {900, "CM"}, {500, "D"}, {400, "CD"}, {100, "C"},
            {90, "XC"},  {50, "L"},   {40, "XL"}, {10, "X"},   {9, "IX"},
            {5, "V"},    {4, "IV"},   {1, "I"},
        };

        string ans;

        for(const auto p : valueSymbols){
            int value = p.first;
            string symbol = p.second;
            while(num >= value){
                num -= value;
                ans += symbol;
            }
        }

        return ans;
    }
};
```
