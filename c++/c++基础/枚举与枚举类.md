在 C++ 中，**枚举（enum）**和**枚举类（enum class）**都可以用来定义一组命名常量，但它们的作用域、类型安全性、隐式转换规则不同。

------

## 1. 普通枚举：`enum`

```cpp
enum Color {
    Red,
    Green,
    Blue
};
```

使用时：

```cpp
Color c = Red;
```

普通枚举的枚举值会直接暴露到当前作用域中。

例如：

```cpp
enum Color {
    Red,
    Green,
    Blue
};

enum TrafficLight {
    Red,    // 错误：Red 已经定义过
    Yellow,
    Green  // 错误：Green 已经定义过
};
```

因为 `Red`、`Green` 已经出现在当前作用域中，所以不能重复。

------

## 2. 枚举类：`enum class`

```cpp
enum class Color {
    Red,
    Green,
    Blue
};
```

使用时必须带上枚举类型名：

```cpp
Color c = Color::Red;
```

枚举值不会污染外部作用域。

```cpp
enum class Color {
    Red,
    Green,
    Blue
};

enum class TrafficLight {
    Red,
    Yellow,
    Green
};
```

这样是合法的，因为：

```cpp
Color::Red
TrafficLight::Red
```

是两个不同作用域中的名字。

------

## 3. 最大区别：类型安全

普通枚举可以隐式转换为整数：

```cpp
enum Color {
    Red,
    Green,
    Blue
};

int x = Red;  // 可以
```

甚至可以这样比较：

```cpp
enum Color {
    Red,
    Green,
    Blue
};

enum Direction {
    Left,
    Right
};

if (Red == Left) {
    // 语法上可以，但逻辑上很危险
}
```

因为普通枚举值本质上容易被当作整数使用。

------

枚举类不会自动转换为整数：

```cpp
enum class Color {
    Red,
    Green,
    Blue
};

int x = Color::Red;  // 错误
```

如果确实需要转换，必须显式转换：

```cpp
int x = static_cast<int>(Color::Red);
```

不同枚举类之间也不能随便比较：

```cpp
enum class Color {
    Red,
    Green,
    Blue
};

enum class Direction {
    Left,
    Right
};

if (Color::Red == Direction::Left) {
    // 错误
}
```

这就是 `enum class` 更安全的地方。

------

## 4. 底层类型

普通枚举和枚举类都可以指定底层类型。

普通枚举：

```cpp
enum Color : unsigned char {
    Red,
    Green,
    Blue
};
```

枚举类：

```cpp
enum class Color : unsigned char {
    Red,
    Green,
    Blue
};
```

如果不指定，编译器会选择一个合适的整型作为底层类型。

------

## 5. 总结对比

| 特性           | enum             | enum class         |
| -------------- | ---------------- | ------------------ |
| 枚举值作用域   | 暴露到外部作用域 | 限定在枚举类型内部 |
| 使用方式       | `Red`            | `Color::Red`       |
| 是否隐式转 int | 可以             | 不可以             |
| 类型安全       | 较弱             | 较强               |
| 枚举名冲突     | 容易冲突         | 不容易冲突         |
| 推荐使用       | 老代码、简单场景 | 现代 C++ 推荐      |

------

## 6. 推荐写法

现代 C++ 中一般优先使用：

```cpp
enum class Color {
    Red,
    Green,
    Blue
};
```

因为它更安全、更清晰。

例如：

```cpp
enum class WeaponType {
    Sword,
    Bow,
    Staff
};

WeaponType weapon = WeaponType::Sword;

if (weapon == WeaponType::Sword) {
    // 使用剑
}
```

这样代码含义非常明确，不容易和其他枚举值混淆。
