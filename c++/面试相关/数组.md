```c++
char a[] = "12345";

char* p = a;

cout << sizeof(a) << endl;  //6
cout << sizeof(p) << endl;  //8

cout << strlen(a) << endl;  //5
cout << strlen(p) << endl;  //5

const char* q = "World";
cout << sizeof(q) << endl;  //8
cout << strlen(q) << endl;  //5
```

1. 字符数组a在初始化时，会在12345后面加一个**空字符'\0'**来表示这是字符串的末尾，所以sizeof会输出6
2. 数组名a在很多时候会**退化**为指向第一个元素的指针，但是他的真实含义**绝对不是指向第一个元素的指针**，而是包含**整个数组**的一块整体；而指针p真的就**只是一个指针**，他并**不知道**自己指向的是一块连续的数组内存，所以sizeof就是p的大小8
3. **strlen**是一个专用于数组的函数，他知道字符数组的结尾是'\0'，所以他不会把'\0'算进去，所以输出5
4. **strlen**会以指针的形式取寻找'\0'，所以他会沿着p指针寻找，最后输出也是5
5. 字符串字面量返回的是他首个元素的地址。q只是一个指针，所以sizeof自然是8
6. strlen会沿着指针q去寻找'\0'，所以是5

#### 数组的初始化

数组在初始化的时候，必须得确定他的大小，而确定大小有两种方法

```c++
//1.直接声明数组的大小，此时这个数组的类型为int[100]，拥有一百个int类型的占位符,sizeof(str)的结果为400
int arr[100];

//2.给数组赋初值，此时这个数组的类型为int[3]，sizeof(str)的结果为12
int arr[] = {1, 2, 3}
```

#### 指向数组的指针，指向数组元素的指针，指针数组

##### 数组指针（指向数组的指针）

指向数组的指针在创建时需要声明数组的类型

```c++
int (*p)[4];
```

类型为int*[4]的指针只能指向类型为int[4]的数组

```c++
int arr[] = {1, 2, 3};
int (*p)[4];
p = &arr;     //错误，因为int*[4]的指针不能指向类型为int[3]的数组
```

==&arr是整个数组的地址，类型为int*[4]，==如果对p进行p++操作，会跨越整个数组的地址，而不是只跨越一个元素

```c++
int arr[] = {1, 2, 3, 4};
int (*p)[4];
p = &arr;
```

##### 数组元素指针（其实就是普通指针）

数组元素指针就是普通指针，类型为int*

```c++
int arr[] = {1, 2, 3, 4};
int* p = &arr[1];
cout << *p << endl;   //输出arr[1]的值2
p++;
cout << *p << endl;   //输出arr[2]的值3
```

取数组元素的地址除了直接写&arr[1]之外，还可以将数组名用于赋值，==数组名在赋值的时候会自动退化成指向数组第一个元素的指针，==类型为int*

```c++
int arr[] = {1, 2, 3, 4};
int* p = arr;    //arr自动退化成了&arr[1]，类型为int*
cout << *p << endl;   //输出arr[1]的值2
p++;
cout << *p << endl;   //输出arr[2]的值3
```

这种退化还体现在函数的传参过程

​	这里arr是int[4]，而参数是int[5]，很明显类型不匹配，但是并不会报错，==因为无论是函数参数int arr[5]，还是arr，都退化成了指针==

```c++
void func(int arr[5]) {    //等价于void func(int* arr)
    cout << sizeof(arr) << endl;  //8，一个指针的大小
}

int main() {
    int arr[] = {1, 2, 3, 4};
    cout << sizeof(arr) << endl;   //16，四个int的大小

    func(arr);    //等价于func(*arr[0])
    
    return 0;
}
```

##### 指针数组

当我们第一眼看到`int* arr[10]`，会下意识的以为arr是一个指向int[10]的数组，实际上并不是，这是一个装着十个int*的数组

```c++
int* arr[5];
cout << sizeof(arr) << endl;  //40，即五个指针
```

#### 数组的拷贝

​	数组并不能通过等号=来直接进行拷贝

​	有一种方法是通过memcpy来进行内存拷贝

```c++
int arr[] = {1, 2 ,3};

int arr2[sizeof(arr) / sizeof(arr[0])];   //先创建一个容量不小于arr的数组，sizeof是12，除以4才是数组的大小

memcpy(arr2, arr, sizeof(arr));            //将arr的sizeof(arr)大小的内存拷贝给arr2，内存的大小为12
```

还有一种方法是用copy

```c++
int arr[] = {1, 2, 3};
int arr2[std::size(arr)];

std::copy(std::begin(arr), std::end(arr), std::begin(arr2));

```

如果是字符数组，还可以用strcpy

```c++
char str[] = "hello";

char str2[sizeof(str) / sizeof(str[0])];

strcpy(str2, str);
```
