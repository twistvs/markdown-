#### define的基本概念

​	define是**宏定义**，在**预处理阶段**进行简单的**文本替换**，**没有类型检查**

```c++
#define greeting "hello, im faker"

int main() {
    int a = greeting;     //报错，因为字符数组不能赋给int 
    
    string str = greeting;        //正常

    return 0;
}
```

#### define和const的区别

**区别：**

1. 编译阶段：define 是在编译预处理阶段进行替换，const 是在编译阶段确定其值。
2.  安全性：define 定义的宏常量没有数据类型，只是进行简单的替换，不会进行类型安全的检查；const定义的常量是有类型的，是要进行判断的，可以避免一些低级的错误。
3.  内存占用：define 定义的宏常量，在程序中使用多少次就会进行多少次替换，内存中有多个备份，占用的是代码段的空间；const定义的常量占用静态存储区的空间，程序运行过程中只有一份。
4. 调试：define 定义的宏常量不能调试，因为在预编译阶段就已经进行替换了；cons定义的常量可以进行调试。
