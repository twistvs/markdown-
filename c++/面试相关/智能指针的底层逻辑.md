#### unique_ptr

​	==智能指针其实是一个成员为指针的模板类==

**手动实现简单的unique_ptr**

1. 包含一个指针，并且在构造时给这个指针赋值，在析构时清理这个指针
2. 类不支持拷贝构造
3. 类支持转移构造

这里为了简单，就没有写移动赋值，只写了移动构造

```c++
template<typename T>
class UniquePtr {
private:
    T* ptr;         //一个指针

public:
    UniquePtr(T* ptr) {
        this->ptr = ptr;    //构造时给指针赋值
    }

    UniquePtr(const UniquePtr& other) = delete;    //不允许调用拷贝构造函数

    UniquePtr(UniquePtr&& other) {      //支持转移构造函数
        ptr = other.ptr;
        other.ptr = nullptr;
    }
    
    ~UniquePtr() {
        delete ptr;            //在智能指针析构时清除指针
    }

    T get() const {         //一个简单的获取指向的内容的工具函数
        return *ptr;
    }
};
```

**怎么使用我们自己写的unique_ptr**

​	由于make_unique是官方专用的，所以我们用更简单粗暴的new来开内存

```c++
int main() {
    UniquePtr<int> u1(new int(2));    //对象的直接初始化
    
    UniquePtr<int> u2 = new int(3);    //对象的复制初始化

    UniquePtr<int> u3(u1);   //报错，拷贝构造被禁用了
    
    UniquePtr<int> u3(move(u1));      //使用转移构造

    cout << u3.get() << endl;

    return 0;
}
```

**官方的unique_ptr是可以和普通指针一样用*来解引用的，我们可以通过运算符重载实现这一点**

```c++
T operator*() const {
    return *ptr;
}
```

#### shared_ptr

**shared_ptr的使用**

```c++
int main() {
    shared_ptr<int> p = make_shared<int>(6);

    shared_ptr<int> p2 = p;     //shared_ptr支持拷贝构造

    shared_ptr<int> p3 = move(p);  //shared_ptr支持转移构造

    cout << p.use_count() << endl;     //0，因为p的内容已经被转移给p3了
    cout << p2.use_count() << endl;     //2，p2和p3目前共享这个指针

    return 0;
}
```

​	我们发现，p的use_count已经为0了，但是智能指针这个对象本身还是存在的，只是里面的内容空掉了。这是因为智能指针本身是一个对象，他只有在自己生命周期结束的时候才会被销毁

​	虽然p的use_count已经为0了，但是只要他再被赋值，就可以复活

```c++
shared_ptr<int> p = make_shared<int>(6);

shared_ptr<int> p2 = p;

shared_ptr<int> p3 = move(p);

p2.reset();    //我将p2reset了此时只有p3还有内容了

cout << *p3 << endl;   //6

cout << p3.use_count() << endl;   //1

p2 = p3;   //我将p3再赋给p2

cout << *p2 << endl;     //6
cout << p2.use_count() << endl;     //2，p2复活了
```

**手动实现shared_ptr**

​	shared_ptr对指针的管理和unique_ptr差不太多，主要是对计数count的管理

```c++
template<typename T>
class MySharedPtr
{
private:
    T* ptr = nullptr;
    std::size_t* count = nullptr;

    void release()
    {
        if (count && --(*count) == 0)
        {
            delete ptr;
            delete count;
        }

        ptr = nullptr;
        count = nullptr;
    }

public:
    //构造
    explicit MySharedPtr(T* p = nullptr)
        : ptr(p),
          count(p ? new std::size_t(1) : nullptr)
    {
    }

    //拷贝构造
    MySharedPtr(const MySharedPtr& other)
        : ptr(other.ptr), count(other.count)
    {
        if (count)
            ++(*count);
    }

    //移动构造
    MySharedPtr(MySharedPtr&& other) noexcept
        : ptr(other.ptr), count(other.count)
    {
        other.ptr = nullptr;
        other.count = nullptr;
    }

    ~MySharedPtr()
    {
        release();
    }
};
```
