在 C++ 中，`++` 和 `--` 是两个非常常见的运算符，分别称为**自增运算符（Increment Operator）和自减运算符（Decrement Operator**）。

虽然它们的语法简单，但是在 C++ 面试中，经常会结合**前置与后置的区别、指针、迭代器、运算符重载、表达式求值顺序**等知识点进行考察。

下面按照 基本概念 → 前置与后置 → 常见用法 → 底层原理 → 面试考点 的顺序介绍。

# 一、++ 和 -- 的基本概念

`++` 用于让变量的值增加 1，`--` 用于让变量的值减少 1。

```c++
int a = 10;

a++;  // a = 11
a--;  // a = 10

++a;  // a = 11
--a;  // a = 10
```

它们都有两种形式：

| 运算符 | 名称     | 含义               |
| ------ | -------- | ------------------ |
| `++a`  | 前置自增 | 先增加，再返回新值 |
| `a++`  | 后置自增 | 先取得旧值，再增加 |
| `--a`  | 前置自减 | 先减少，再返回新值 |
| `a--`  | 后置自减 | 先取得旧值，再减少 |

注意：无论是前置还是后置，变量本身最终都会发生相同的增减变化。区别主要在于表达式产生的结果。

# 二、前置 ++ 和后置 ++ 的区别（重点）

这是最常见的面试题。

## 1. 前置自增：++i

```c++
int i = 5;

int a = ++i;

cout << i << endl;  // 6
cout << a << endl;  // 6
```

## 2. 后置自增：i++

```c++
int i = 5;

int a = i++;

cout << i << endl;  // 6
cout << a << endl;  // 5
```

## 3. 前置 -- 和后置 -- 同理

```c++
int i = 5;

int a = --i;  // i = 4, a = 4
int i = 5;

int a = i--;  // i = 4, a = 5
```

## 4. 对比总结

| 比较项               | `++i`    | `i++`                |
| -------------------- | -------- | -------------------- |
| 自增时机             | 使用新值 | 使用旧值             |
| i 最终的值           | 增加 1   | 增加 1               |
| 表达式结果           | 新值     | 旧值                 |
| 内置类型表达式值类别 | 左值     | ==右值（纯右值）==   |
| 自定义迭代器开销     | 通常较低 | ==可能需要复制旧值== |

这里有一个非常重要的知识点：

==对于内置整数类型，`++i` 的结果是左值，而 `i++` 的结果是右值。==

例如：

```c++
int i = 5;

int& a = ++i;  // 正确
int& b = i++;  // 错误
```

原因是前置自增返回的是修改后的对象本身，可以绑定到左值引用。

而后置自增产生的是自增之前的值，不能直接绑定到普通的非 `const` 左值引用。

甚至可以写：

```c++
int i = 5;

++i = 10;  // 合法，最终 i = 10
```

但不能写：

```c++
i++ = 10;  // 编译错误，因为i++返回的是一个纯右值
```

这也是理解前置与后置自增底层差异的关键。

## 2. 数组和指针操作（重点）

在 C++ 中，`++` 和 `--` 不仅能操作整数，也能操作指针。

```c++
int arr[] = {10, 20, 30};

int* p = arr;

cout << *p << endl;  // 10

p++;

cout << *p << endl;  // 20

p++;

cout << *p << endl;  // 30
```

这里的 `p++` 并不是简单地将指针的地址数值增加 1，而是让指针移动到下一个元素。

例如，假设 `int` 占用 4 字节：

> [!NOTE]
>
> 对于指针类型的变量T*，对他们使用++，相当于使他们的值加上sizeof(T)

对于指向类型 `T` 的普通对象指针：

```
T* p;
++p;
```

在合法的指针运算范围内，相当于指向下一个 `T` 元素。

因此：

```
char* p1;    // p1++ 通常移动 1 字节
int* p2;     // p2++ 通常移动 4 字节
double* p3;  // p3++ 通常移动 8 字节
```

==实际步长取决于 `sizeof(T)`。==

## 3. \*p++、(\*p)++ 和 ++*p 的区别（高频面试题）

> [!NOTE]
>
> 有一种比较好记的方法，\*p++等价于\*(p++)，++\*p等价于++(\*p)

这是面试中非常容易混淆的地方。

假设：

```c++
int arr[] = {10, 20, 30};
int* p = arr;
```

① `*p++`：先解引用原指针，再让指针后移

```c++
int a = *p++;
```

等价于：

```c++
int a = *(p++);
```

结果：

```c++
a == 10;
p == &arr[1];
```

因为后置 `++` 的优先级高于解引用 `*`。

② `(*p)++`：让指针指向的值增加 1

```c++
(*p)++;
```

执行后：

```c++
arr[0] == 11;
p == &arr[0];
```

指针本身没有移动。

③ `++*p`：**先增加指针指向的值，再使用新值**

```c++
int a = ++*p;
```

等价于：

```c++
int a = ++(*p);
```

执行后：

```c++
arr[0] == 11;
a == 11;
p == &arr[0];
```

三者总结：

| 表达式   | 修改对象       | 表达式产生的值     |
| -------- | -------------- | ------------------ |
| `*p++`   | 指针 p 后移    | 原指针指向的元素值 |
| `(*p)++` | 指向的元素自增 | 元素原来的值       |
| `++*p`   | 指向的元素自增 | 元素自增后的值     |

## 4. STL 迭代器遍历

在 STL 中，`++` 也经常用于迭代器。

```c++
#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> v = {10, 20, 30};

    for (auto it = v.begin(); it != v.end(); ++it) {
        cout << *it << " ";
    }
}
```

输出：

```
10 20 30
```

注意这里推荐写 `++it`，而不是 `it++`。

原因与运算符重载有关，下面会详细解释。

# 四、++ 的底层原理：为什么 ++i 通常比 i++ 更推荐？

这一点属于 C++ 进阶知识，也是面试常考内容。

## 1. 对于内置类型

```c++
int i = 10;

++i;
```

和：

```c++
int i = 10;

i++;
```

如果不使用自增表达式的结果，效果一样。

现代编译器通常可以将它们优化成相同的机器指令，因此对于普通整数，不需要刻意纠结性能。

## 2. 对于自定义类型和迭代器

C++ 允许重载 `++` 运算符。

例如：

```c++
class Counter {
public:
    int value = 0;

    // 前置 ++
    Counter& operator++() {
        ++value;
        return *this;
    }

    // 后置 ++
    Counter operator++(int) {
        Counter temp = *this;
        ++value;
        return temp;
    }
};
```

这里有三个关键点。

**第一：前置 `++` 返回引用。**

```c++
Counter& operator++()
```

它直接修改当前对象，并返回当前对象的引用，一般不需要额外复制。

**第二：后置 `++` 通常返回旧值的副本。**

```c++
Counter operator++(int)
```

为了让表达式能够得到自增前的值，通常需要先保存旧状态。

**第三：后置 `++` 中的 `int` 是什么？**

这个 `int` 只是用来区分前置和后置的占位参数：

```c++
operator++()     // 前置 ++
operator++(int)  // 后置 ++
```

通常不会真正使用这个参数。

因此，对于某些自定义类和迭代器：

```c++
++it;  // 通常直接修改对象
it++;  // 可能需要额外创建旧值副本
```

**面试结论：当不需要旧值时，推荐优先使用前置 `++`，尤其是处理迭代器和自定义类型时。** 不过，编译器有时也能优化掉后置形式的额外开销，不能认为 `it++` 一定更慢。

# 五、++ 和 -- 的常见陷阱

## 1. 在同一个表达式中多次修改变量

```c++
int i = 1;

int a = i++ + ++i;
```

这段代码存在**未定义行为（Undefined Behavior）。**

因为 `+` 两侧操作数的求值没有规定先后顺序，而程序在未建立必要顺序关系的情况下多次修改了 `i`。

不能根据某个编译器的运行结果推断标准规定的结果。

建议改成：

```c++
int i = 1;

int a = i++;
int b = ++i;

int result = a + b;
```

这样逻辑明确，不会产生求值顺序问题。

## 2. unsigned 无符号整数的自减陷阱

```c++
unsigned int i = 0;

i--;

cout << i << endl;
```

在常见的 32 位 `unsigned int` 环境下，输出：

```
4294967295
```

原因是无符号整数的运算按模 \(2^N\) 进行。

因此，在对 `vector` 等容器的索引进行倒序遍历时，不要写：

```c++
for (size_t i = v.size() - 1; i >= 0; --i) {
    cout << v[i];
}
```

因为 `size_t` 是无符号类型，`i >= 0` 永远成立，而且空容器时还会出现下溢问题。

可以改成：

```c++
for (size_t i = v.size(); i > 0; --i) {
    cout << v[i - 1];
}
```

这样可以正确处理空容器。

## 3. 在条件表达式中使用 ++ 和 --

例如：

```c++
int i = 3;

while (i--) {
    cout << i << " ";
}
```

输出：

```
2 1 0
```

要特别注意，最后一次判断条件时，`i` 原来是 0，表达式 `i--` 的结果为 0，所以循环停止，但是自减仍然执行了。

因此循环结束后：

```c++
i == -1;
```

这个知识点也是容易出现的面试题。

## 4. const 变量不能使用 ++ 和 --

```c++
const int a = 10;

a++;  // 编译错误
--a;  // 编译错误
```

因为 `++` 和 `--` 会修改操作数，而 `const` 对象不能被修改。

此外，`++` 或 `--` 也不能直接作用于临时的整数值：

```c++
++10;  // 编译错误
10--;  // 编译错误
```

# 七、面试时应该如何回答？

如果面试官问：

“C++ 中前置 ++ 和后置 ++ 有什么区别？”

可以这样回答：

> C++ 中的 `++` 和 `--` 分别表示自增和自减，都有前置和后置两种形式。
>
> 以前置 `++` 和后置 `++` 为例，前置 `++` 先修改变量，再产生修改后的值；后置 `++` 产生修改前的值，同时完成变量的自增。
>
> 对于内置整数类型，前置 `++` 的表达式结果是左值，后置 `++` 的结果是纯右值。
>
> 对于自定义类型和 STL 迭代器，前置 `++` 通常返回对象引用，而后置 `++` 通常需要保存旧值并返回副本，因此在不需要旧值时，习惯上优先使用前置 `++`。
>
> 此外，`++` 和 `--` 还常用于指针移动、数组遍历和循环控制，需要特别注意运算符优先级、无符号整数下溢，以及复杂表达式中的求值顺序问题。

最后建议重点掌握三个知识点：`++i` 与 `i++` 的返回值和返回类型差异、`*p++` 与 `(*p)++` 的区别、以及前置与后置运算符重载的实现。这三个方向最容易从基础语法延伸到 C++ 对象模型、运算符重载和 STL 迭代器等进阶问题。
