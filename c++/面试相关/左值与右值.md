- **左值**是表达式结束后依旧存在的**持久对象**，**右值**是表达式结束后就不再存在的**临时对象**
- **左值引用**就是我们常说的**别名**，必须绑定在一个左值上
- **右值引用**绑定右值，但是右值引用本质上是一个左值，因为他在表达式结束后依旧存在

| 左值                    | 右值                    |
| ----------------------- | ----------------------- |
| 可以取地址：&x          | 不能取地址              |
| 可以作为函数返回值      | 不能作为函数返回值      |
| 可以绑定到左值引用 int& | 可以绑定到右值引用int&& |


```c++
# include <iostream>

int main() {
	int a = 10;
	//左值引用必须绑定左值
	int& b = a;
    //int & b = 10  错误，10作为字面量，是右值
    
    //右值引用绑定右值
	int&& c = 10;
    //int&& c = a;  错误，a是左值，不能被右值引用

	std::cout << c << std::endl;
	
	return 0;
}
```

#### 右值与std::move

> [!NOTE]
>
> 如果单从名字上看，move似乎是用于移动的函数，其实并不是，move的作用只是把一个左值转换为右值

​	众所周知，左值是不能被右值引用的，如果想要让一个左值被右值引用，就需要用到move

```c++
int a = 1;

int&& b = std::move(a);

cout << a << endl;  //输出1，可以看出，move并没有移动a，a还是原原本本的待在原处
cout << b << endl;  //输出1，
```

这样操作之后，b虽然是右值引用，但是他的功能和左值引用一样，他和a就是同一个东西，修改他们的值的时候会互相影响
