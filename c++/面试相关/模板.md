#### 函数模板

函数模块可以自动推导类型，也可以手动填类型

```c++
template<typename T>
T func(T a, T b) {
    return a + b;
}

int main() {
    int a = 1;
    int b = 2;
    int c = func(a, b);    //自动推导T为int
    int d = func<int>(a, b);   //手动指定T为int

    cout << c << d << endl;

    return 0;
}
```

#### 类模板

类模板必须手动指定类型

```c++
template<typename T>
class Person {
public:
    T a;
};

int main() {
    Person<int> p1;
    p1.a = 2;
    
    Person<char> p2;
    p2.a = 'c';

    return 0;
}
```

#### 模板特化

可以手动特化某些情况下的模板

```c++
template<typename T>
T func(T a, T b) {
    return a + b;
}

//特别指定T为int时，返回a-b
template<>
int func<int>(int a, int b) {
    return a - b;
}

int main() {
    cout << func(1, 2) << endl;
    cout << func(2.2, 1.1) << endl;

    return 0;
}
```
