#### 初始化一个对象

如果一个类A有一个有参构造函数

```c++
class A
{
public:
    int a;
    A(int a) {
        this->a = a;
    }
};
```

那么

```c++
A a = 2;
A b(2);
```

这两种写法都是在初始化对象，A = b(2)是直接初始化，A a = 2是复制初始化；**注意区分初始化和赋值**

如果在构造函数前面加上explicit

```c++
explicit A(int a) {
        this->a = a;
    }
```

那么这个构造函数无法被复制初始化调用，只能用直接初始化

#### 缺省的拷贝构造

如果一个类的拷贝构造缺省了，那么编辑器会默认补充一个拷贝构造

```c++
class A {
public:
    int x;
    std::string name;

    // 编译器生成的效果大致相当于：
    A(const A& other)
        : x(other.x),
          name(other.name)
    {}
};
```

可以看到，默认的拷贝构造会简单粗暴的把类里面的成员都进行拷贝过来，此时对象的拷贝属于**浅拷贝**
如果A的成员包括指针，并且在析构中释放指针指向的内存的话，**浅拷贝就会导致多个对象对同一块内存执行多次释放**。

#### 移动语义

​	如果此时有一个类Person

```c++
class Person {
public:
    int* p;
    
    Person(int a) {
        p = new int(a);
    }
    
    ~Person() {
        delete p;
    }
};
```

如果我们采用**默认拷贝构造**，实现**浅拷贝**。会出现内存被重复释放的问题，所以这样是不合适的

**手动实现深拷贝**

```c++
class Person {
public:
    int* p;

    Person(int a) {
        p = new int(a);
    }

    Person(const Person& other) {
        p = new int(*other.p);
    }

    ~Person() {
        delete p;
    }
};
```

通过给自己的p指针新开一块内容，我们实现了两个对象的p指向不同位置的同一个内容，实现了**深拷贝**，提高了代码的**安全性**

但是深拷贝需要把内容复制一份，如果我希望把p2的内容**转移**到p1，随后p2就不再投入使用，那么用这样的深拷贝方法似乎有点**浪费性能**

**移动语义**

​	移动语义的作用是可以把p2的内容**搬到**p1，在不产生内存复制的情况下，清空p2并且把内容全部转移至p1

1. p2的普通变量把值赋给p1，然后给自己赋0
2. p2的指针把值赋给p1，然后让自己nullptr

有两种比较常见的执行方式：**移动构造函数**和**移动赋值运算符**

**移动构造函数**

```c++
class Person {
public:
    int* p;
	int age;

    Person(int a, int age) {
        p = new int(a);
        this->age = age;
    }

    Person(Person&& other) noexcept {
        p = other.p;
        other.p = nullptr;
        this->age = other.age;
        other.age = 0;
    }

    ~Person() {
        delete p;
    }
};

int main(){
    Person p2(10, 18);
    
    Person p1(std::move(p2));
    Person p1 = std::move(p2);  //这两种写法都可以，和拷贝构造同理
}
```

在执行拷贝构造的时候实现移动语义，把p2的内容都转移到p1里面

**移动赋值运算符**

```c++
class Person {
public:
    int* p;

    Person(int a) {
        p = new int(a);
    }

    Person(Person&& other) noexcept {
        p = other.p;
        other.p = nullptr;
    }

    Person& operator=(Person&& other) noexcept {
        if (this != &other) {
            delete p;
            p = other.p;
            other.p = nullptr;
        }

        return *this;
    }

    ~Person() {
        delete p;
    }
};
```

在两个对象p1和p2都已经创建好的情况下，通过赋值的方式实现移动语义
