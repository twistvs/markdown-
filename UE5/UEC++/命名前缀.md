UE C++ 里的类名前缀是一套约定，用来快速看出这个类型属于什么类别。最常见规则如下。

| 前缀 | 含义                           | 示例                                                        |
| ---- | ------------------------------ | ----------------------------------------------------------- |
| `A`  | 继承自 `AActor` 的类           | `ACharacter`, `APlayerController`, `AMyEnemy`               |
| `U`  | 继承自 `UObject`，但不是 Actor | `UActorComponent`, `UUserWidget`, `UAbilitySystemComponent` |
| `F`  | 普通结构体 / 非 UObject 类型   | `FVector`, `FRotator`, `FGameplayAttributeData`             |
| `I`  | 接口类                         | `IAbilitySystemInterface`, `IMyInteractInterface`           |
| `E`  | 枚举类型                       | `ECollisionChannel`, `EMovementMode`                        |
| `T`  | 模板类                         | `TArray`, `TMap`, `TSubclassOf`                             |
| `S`  | Slate UI 控件类                | `SWidget`, `SButton`                                        |
| `G`  | 全局变量                       | `GEngine`, `GWorld`                                         |
| `b`  | 布尔变量前缀                   | `bIsDead`, `bCanMove`                                       |

------

## 1. `A`：Actor 类

只要你的类继承自 `AActor` 或它的子类，类名一般用 `A` 开头。

例如：

```cpp
class AMyActor : public AActor
{
};
```

角色类：

```cpp
class AMyCharacter : public ACharacter
{
};
```

控制器类：

```cpp
class AMyPlayerController : public APlayerController
{
};
```

因为它们最终都继承自：

```cpp
AActor
```

所以都用 `A`。

------

## 2. `U`：UObject 类

如果类继承自 `UObject`，但不是 `AActor`，一般用 `U` 开头。

例如：

```cpp
class UMyActorComponent : public UActorComponent
{
};
```

Widget：

```cpp
class UMyUserWidget : public UUserWidget
{
};
```

GAS AttributeSet：

```cpp
class UBaseAttributeSet : public UAttributeSet
{
};
```

Gameplay Ability：

```cpp
class UFireballAbility : public UGameplayAbility
{
};
```

这些都不是 Actor，但都是 UObject 系统的一部分，所以用 `U`。

------

## 3. `F`：结构体 / 普通数据类型

`F` 常用于 `struct`，也用于很多非 UObject 的普通类型。

例如：

```cpp
USTRUCT(BlueprintType)
struct FItemData
{
    GENERATED_BODY()

    UPROPERTY(EditAnywhere, BlueprintReadWrite)
    int32 ItemID;
};
```

常见 UE 类型：

```cpp
FVector
FRotator
FTransform
FString
FName
FGameplayTag
FGameplayEffectSpec
```

你自己写数据结构时也通常用 `F`：

```cpp
FWeaponData
FCharacterStats
FInventorySlot
```

------

## 4. `I`：接口

接口类一般用 `I` 开头。

例如：

```cpp
class IMyInteractInterface
{
};
```

UE 接口通常会有两个类：

```cpp
UINTERFACE()
class UMyInteractInterface : public UInterface
{
    GENERATED_BODY()
};

class IMyInteractInterface
{
    GENERATED_BODY()
};
```

这里：

```cpp
UMyInteractInterface
```

是 UObject 反射用的接口包装类。

```cpp
IMyInteractInterface
```

是真正写接口函数的 C++ 接口类。

------

## 5. `E`：枚举

枚举类型一般用 `E` 开头。

例如：

```cpp
UENUM(BlueprintType)
enum class EWeaponType : uint8
{
    Sword,
    Bow,
    Staff
};
```

常见 UE 枚举：

```cpp
ECollisionChannel
ETraceTypeQuery
EMovementMode
EGameplayModOp
```

------

## 6. `T`：模板类型

UE 的模板容器和模板工具类一般用 `T` 开头。

例如：

```cpp
TArray<int32> Numbers;
TMap<FName, int32> ItemCounts;
TSet<AActor*> HitActors;
TSubclassOf<AActor> ActorClass;
TWeakObjectPtr<AActor> WeakActor;
TObjectPtr<UObject> ObjectPtr;
```

你自己写模板类时，也可以用 `T` 开头，但普通项目里不一定常写。

------

## 7. `S`：Slate 控件

`S` 主要用于 Slate UI 系统。

例如：

```cpp
SWidget
SButton
STextBlock
SCompoundWidget
```

如果你主要写 UMG 蓝图 UI，平时较少直接写 `S` 类。
UMG 里的 Widget 是 `UUserWidget`，所以是 `U` 前缀。

------

## 8. `b`：布尔变量

布尔变量一般用小写 `b` 开头。

例如：

```cpp
bool bIsDead;
bool bCanAttack;
bool bIsLockingOn;
bool bHasWeapon;
```

UPROPERTY 也一样：

```cpp
UPROPERTY(EditAnywhere, BlueprintReadWrite)
bool bIsSprinting;
```

这是 UE 非常常见的风格。

------

## 9. 常见例子：你的 GAS 项目

比如 AttributeSet：

```cpp
UCLASS()
class GAS_DEMO_API UBaseAttributeSet : public UAttributeSet
{
    GENERATED_BODY()
};
```

为什么是 `UBaseAttributeSet`？

因为：

```cpp
UAttributeSet
```

继承自 `UObject`，所以你的子类也用 `U`。

------

Gameplay Ability：

```cpp
UCLASS()
class GAS_DEMO_API UGA_MeleeAttack : public UGameplayAbility
{
    GENERATED_BODY()
};
```

也是 `U`，因为 `UGameplayAbility` 是 UObject 类型。

------

角色：

```cpp
UCLASS()
class GAS_DEMO_API AMyCharacter : public ACharacter
{
    GENERATED_BODY()
};
```

是 `A`，因为 `ACharacter` 继承自 `AActor`。

------

数据结构：

```cpp
USTRUCT(BlueprintType)
struct FDamageInfo
{
    GENERATED_BODY()
};
```

是 `F`，因为它是结构体。

------

枚举：

```cpp
UENUM(BlueprintType)
enum class EAbilityInputID : uint8
{
    None,
    Confirm,
    Cancel,
    Attack,
    Skill
};
```

是 `E`，因为它是枚举。

------

## 10. 变量命名一般不用这些大写前缀

例如角色类是：

```cpp
AMyCharacter
```

但变量名通常写：

```cpp
AMyCharacter* MyCharacter;
```

或者 UE5 推荐 UObject 指针用：

```cpp
TObjectPtr<AMyCharacter> MyCharacter;
```

不要把变量也写成：

```cpp
AMyCharacter* AMyCharacter;
```

类名前缀是类型命名规则，不是变量命名规则。

------

## 11. 总结规则

最常记这几个就够了：

```text
A = Actor
U = UObject
F = Struct / 普通数据类型
I = Interface
E = Enum
T = Template
S = Slate
b = bool
```

你的判断方式可以很简单：

```text
能放进关卡、能 Spawn、继承 Actor → A

不是 Actor，但继承 UObject → U

只是数据结构 struct → F

接口 → I

枚举 → E

布尔变量 → b
```

例如：

```cpp
AMyEnemy              // 敌人 Actor
UHealthComponent      // 血量组件
FEnemyData            // 敌人数据结构
IInteractable         // 可交互接口
EWeaponType           // 武器类型枚举
bool bIsAttacking     // 是否正在攻击
```
