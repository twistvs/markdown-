UE5 的“反射说明符”主要写在这些宏里：

```cpp
UCLASS(...)
USTRUCT(...)
UENUM(...)
UPROPERTY(...)
UFUNCTION(...)
UMETA(...)
meta=(...)
```

Epic 官方文档把它们分成 **Class Specifiers、Property Specifiers、Function Specifiers、Metadata Specifiers** 等类别；其中 `meta=(...)` 里的内容主要服务编辑器和蓝图，官方也提醒：**Metadata 只存在于编辑器中，不要依赖 Metadata 写游戏运行逻辑**。([Epic Games Developers](https://dev.epicgames.com/documentation/unreal-engine/class-specifiers?utm_source=chatgpt.com))

------

# 1. UCLASS 类说明符

用于描述一个 UObject 类在编辑器、蓝图、配置、序列化等系统中的行为。

常见写法：

```cpp
UCLASS(Blueprintable, BlueprintType)
class MYGAME_API AMyActor : public AActor
{
    GENERATED_BODY()
};
```

常用 `UCLASS` 说明符：

| 说明符                         | 作用                                |
| ------------------------------ | ----------------------------------- |
| `Blueprintable`                | 允许这个类被蓝图继承                |
| `NotBlueprintable`             | 不允许被蓝图继承                    |
| `BlueprintType`                | 允许这个类作为蓝图变量类型          |
| `Abstract`                     | 抽象类，不能直接实例化              |
| `EditInlineNew`                | 可以在 Details 面板中内联创建对象   |
| `DefaultToInstanced`           | 这个类的对象默认作为实例化子对象    |
| `Config=Game`                  | 允许类的属性从配置文件读取          |
| `DefaultConfig`                | 默认配置保存到默认配置文件          |
| `Transient`                    | 该类对象通常不参与持久化保存        |
| `Placeable`                    | Actor 类可以被放入关卡              |
| `NotPlaceable`                 | Actor 类不能被放入关卡              |
| `MinimalAPI`                   | 只导出最低限度符号，常用于引擎模块  |
| `HideCategories=(...)`         | 在编辑器中隐藏某些分类              |
| `ShowCategories=(...)`         | 显示某些分类                        |
| `AutoExpandCategories=(...)`   | 默认展开某些分类                    |
| `AutoCollapseCategories=(...)` | 默认折叠某些分类                    |
| `AdvancedClassDisplay`         | 类中的属性默认显示在高级选项中      |
| `ClassGroup=(...)`             | 组件类在 Add Component 面板中的分类 |
| `meta=(...)`                   | 添加元数据                          |

例子：

```cpp
UCLASS(Blueprintable, BlueprintType, ClassGroup=(Custom), meta=(BlueprintSpawnableComponent))
class UMyHealthComponent : public UActorComponent
{
    GENERATED_BODY()
};
```

这里：

```cpp
Blueprintable
```

表示可以创建这个类的蓝图子类。

```cpp
BlueprintType
```

表示它可以作为蓝图变量类型。

```cpp
meta=(BlueprintSpawnableComponent)
```

表示它可以在蓝图编辑器中作为组件添加。

# 2. USTRUCT 结构体说明符

用于让结构体进入 UE 反射系统。

常见写法：

```cpp
USTRUCT(BlueprintType)
struct FWeaponData
{
    GENERATED_BODY()

    UPROPERTY(EditAnywhere, BlueprintReadWrite)
    float Damage;
};
```

常用 `USTRUCT` 说明符：

| 说明符          | 作用                             |
| --------------- | -------------------------------- |
| `BlueprintType` | 允许结构体作为蓝图变量类型       |
| `Atomic`        | 序列化时整体处理                 |
| `NoExport`      | 不生成标准导出代码，较少直接使用 |
| `meta=(...)`    | 添加元数据                       |

最常用的基本就是：

```cpp
USTRUCT(BlueprintType)
```

官方文档也提到，`BlueprintType` 的结构体可以自动生成 Make Struct 节点；如果结构体中有 `BlueprintReadOnly` 或 `BlueprintReadWrite` 属性，也可以生成 Break Struct 节点。([Epic Games Developers](https://dev.epicgames.com/documentation/unreal-engine/structs-in-unreal-engine?utm_source=chatgpt.com))

# 3. UENUM 枚举说明符

用于让枚举进入反射系统，通常是为了蓝图可见。

常见写法：

```cpp
UENUM(BlueprintType)
enum class EWeaponType : uint8
{
    Sword UMETA(DisplayName="Sword"),
    Bow   UMETA(DisplayName="Bow"),
    Staff UMETA(DisplayName="Staff")
};
```

常用 `UENUM` 说明符：

| 说明符          | 作用                     |
| --------------- | ------------------------ |
| `BlueprintType` | 允许枚举作为蓝图变量类型 |
| `meta=(...)`    | 添加枚举元数据           |

枚举值后面常用 `UMETA`：

| UMETA               | 作用                       |
| ------------------- | -------------------------- |
| `DisplayName="xxx"` | 在编辑器或蓝图中显示的名字 |
| `Hidden`            | 隐藏该枚举值               |
| `ToolTip="xxx"`     | 鼠标悬停提示               |
| `Spacer`            | 用于编辑器显示分隔，较少用 |

例子：

```cpp
UENUM(BlueprintType)
enum class EDamageType : uint8
{
    Physical UMETA(DisplayName="物理伤害"),
    Fire     UMETA(DisplayName="火焰伤害"),
    Ice      UMETA(DisplayName="冰霜伤害"),

    HiddenMax UMETA(Hidden)
};
```

# 4. UPROPERTY 属性说明符

`UPROPERTY` 是最常用的一类说明符，用于控制变量是否能编辑、是否能蓝图访问、是否保存、是否复制、是否参与 GC 等。官方文档说明，Property Specifiers 用来控制属性在引擎和编辑器中的行为。([Epic Games Developers](https://dev.epicgames.com/documentation/unreal-engine/unreal-engine-uproperties?utm_source=chatgpt.com))

基本写法：

```cpp
UPROPERTY(EditAnywhere, BlueprintReadWrite, Category="Stats")
float Health;
```

------

## 4.1 编辑器可见 / 可编辑相关

| 说明符                | 作用                                         |
| --------------------- | -------------------------------------------- |
| `EditAnywhere`        | 类默认值和实例都可编辑                       |
| `EditDefaultsOnly`    | 只能在类默认值中编辑                         |
| `EditInstanceOnly`    | 只能在实例中编辑                             |
| `VisibleAnywhere`     | 类默认值和实例都可见，但不可编辑             |
| `VisibleDefaultsOnly` | 只在类默认值中可见                           |
| `VisibleInstanceOnly` | 只在实例中可见                               |
| `AdvancedDisplay`     | 放到高级展开项中                             |
| `SimpleDisplay`       | 即使类默认高级显示，也把该属性显示在普通区域 |
| `Category="xxx"`      | 设置 Details 面板分类                        |

例子：

```cpp
UPROPERTY(EditAnywhere, Category="Combat")
float AttackRange = 200.f;

UPROPERTY(VisibleAnywhere, Category="Components")
TObjectPtr<USkeletalMeshComponent> MeshComp;
```

------

## 4.2 蓝图访问相关

| 说明符                     | 作用                        |
| -------------------------- | --------------------------- |
| `BlueprintReadOnly`        | 蓝图可读，不可写            |
| `BlueprintReadWrite`       | 蓝图可读可写                |
| `BlueprintGetter=FuncName` | 指定蓝图读取时调用的 Getter |
| `BlueprintSetter=FuncName` | 指定蓝图写入时调用的 Setter |

例子：

```cpp
UPROPERTY(EditAnywhere, BlueprintReadWrite, Category="Stats")
float Health;
```

------

## 4.3 序列化 / 保存相关

| 说明符                     | 作用                             |
| -------------------------- | -------------------------------- |
| `Transient`                | 不保存，加载时重置               |
| `DuplicateTransient`       | 复制对象时重置                   |
| `NonPIEDuplicateTransient` | PIE 复制时不重置，其他复制时重置 |
| `SaveGame`                 | 可被 SaveGame 系统保存           |
| `Config`                   | 从配置文件读取                   |
| `GlobalConfig`             | 从基类全局配置读取               |
| `Localized`                | 本地化相关，较少直接使用         |
| `TextExportTransient`      | 文本导出时跳过                   |

例子：

```cpp
UPROPERTY(SaveGame)
int32 PlayerLevel;

UPROPERTY(Transient)
float RuntimeOnlyValue;
```

------

## 4.4 网络复制相关

| 说明符                       | 作用                          |
| ---------------------------- | ----------------------------- |
| `Replicated`                 | 属性参与网络复制              |
| `ReplicatedUsing=OnRep_Func` | 属性复制后调用 RepNotify 函数 |
| `NotReplicated`              | 不复制，常用于结构体成员      |

例子：

```cpp
UPROPERTY(ReplicatedUsing=OnRep_Health)
float Health;

UFUNCTION()
void OnRep_Health();
```

官方复制文档也把 `Replicated` 和 `ReplicatedUsing` 作为属性复制的两个主要选择。([Epic Games Developers](https://dev.epicgames.com/documentation/unreal-engine/replicate-actor-properties-in-unreal-engine?utm_source=chatgpt.com))

------

## 4.5 对象引用 / 子对象相关

| 说明符                       | 作用                                |
| ---------------------------- | ----------------------------------- |
| `Instanced`                  | 属性引用的是实例化子对象            |
| `Export`                     | 对象导出时一起导出引用对象          |
| `ContainsInstancedReference` | 包含实例化对象引用                  |
| `EditInline`                 | 允许内联编辑对象，旧式/较少直接使用 |

例子：

```cpp
UPROPERTY(EditAnywhere, Instanced)
TObjectPtr<UMyEffectObject> EffectObject;
```

------

## 4.6 资源、资产、编辑器搜索相关

| 说明符                    | 作用                               |
| ------------------------- | ---------------------------------- |
| `AssetRegistrySearchable` | 可以被资产注册表搜索               |
| `Interp`                  | 可被 Sequencer / Matinee 插值编辑  |
| `EditFixedSize`           | 数组大小固定，编辑器中不能改变长度 |
| `NoClear`                 | 编辑器中不显示清除按钮             |
| `SkipSerialization`       | 跳过序列化                         |

------

## 4.7 常用 UPROPERTY 元数据 meta

`meta=(...)` 不完全等同于普通说明符，它通常影响编辑器和蓝图显示。

常见写法：

```cpp
UPROPERTY(EditAnywhere, BlueprintReadWrite, meta=(ClampMin="0", ClampMax="100"))
float Health;
```

常用 `UPROPERTY meta`：

| meta                        | 作用                                 |
| --------------------------- | ------------------------------------ |
| `ClampMin="0"`              | 最小限制                             |
| `ClampMax="100"`            | 最大限制                             |
| `UIMin="0"`                 | 编辑器滑条最小值                     |
| `UIMax="100"`               | 编辑器滑条最大值                     |
| `EditCondition="bEnable"`   | 满足条件才可编辑                     |
| `EditConditionHides`        | 条件不满足时隐藏                     |
| `DisplayName="xxx"`         | 显示名称                             |
| `ToolTip="xxx"`             | 鼠标提示                             |
| `AllowPrivateAccess="true"` | 允许蓝图访问 private 属性            |
| `MakeEditWidget="true"`     | FVector 等属性在视口中显示可拖拽控件 |
| `ExposeOnSpawn="true"`      | Spawn Actor 节点中暴露该参数         |
| `AllowedClasses="xxx"`      | 限制可选资源类型                     |
| `MustImplement="xxx"`       | 限制对象必须实现某接口               |
| `BindWidget`                | UMG 中绑定同名控件                   |
| `BindWidgetOptional`        | UMG 中可选绑定同名控件               |

例子：

```cpp
UPROPERTY(EditAnywhere, BlueprintReadWrite, Category="Stats",
          meta=(ClampMin="0", ClampMax="100", UIMin="0", UIMax="100"))
float Health = 100.f;
```

# 5. UFUNCTION 函数说明符

`UFUNCTION` 用于让函数进入反射系统，常用于蓝图调用、RPC、事件、控制台命令等。官方文档说明，Function Specifiers 用来控制函数在引擎和编辑器中的行为。([Epic Games Developers](https://dev.epicgames.com/documentation/unreal-engine/ufunctions-in-unreal-engine?utm_source=chatgpt.com))

基本写法：

```cpp
UFUNCTION(BlueprintCallable, Category="Combat")
void Attack();
```

------

## 5.1 蓝图调用相关

| 说明符                        | 作用                                         |
| ----------------------------- | -------------------------------------------- |
| `BlueprintCallable`           | 蓝图可调用，有执行引脚                       |
| `BlueprintPure`               | 蓝图纯函数，无执行引脚，通常不修改状态       |
| `BlueprintImplementableEvent` | C++ 声明，蓝图实现                           |
| `BlueprintNativeEvent`        | C++ 可提供默认实现，蓝图可重写               |
| `BlueprintAuthorityOnly`      | 蓝图中只有 Authority 机器可执行              |
| `BlueprintCosmetic`           | 装饰性函数，通常不在 dedicated server 上运行 |
| `CallInEditor`                | 可以在编辑器 Details 面板中点击执行          |

例子：

```cpp
UFUNCTION(BlueprintCallable, Category="Combat")
void Attack();

UFUNCTION(BlueprintPure, Category="Stats")
float GetHealthPercent() const;
```

------

## 5.2 网络 RPC 相关

| 说明符           | 作用                              |
| ---------------- | --------------------------------- |
| `Server`         | 客户端调用，在服务器执行          |
| `Client`         | 服务器调用，在指定客户端执行      |
| `NetMulticast`   | 服务器调用，在所有客户端执行      |
| `Reliable`       | 可靠 RPC                          |
| `Unreliable`     | 不可靠 RPC                        |
| `WithValidation` | 旧式 RPC 校验写法，UE5 中较少使用 |

例子：

```cpp
UFUNCTION(Server, Reliable)
void ServerFire();

UFUNCTION(NetMulticast, Unreliable)
void MulticastPlayFireEffect();
```

------

## 5.3 执行方式 / 控制台相关

| 说明符            | 作用                     |
| ----------------- | ------------------------ |
| `Exec`            | 可以通过控制台命令调用   |
| `CustomThunk`     | 自定义蓝图 VM 调用 thunk |
| `SealedEvent`     | 防止事件继续被重写       |
| `ServiceRequest`  | RPC 服务请求相关，较少用 |
| `ServiceResponse` | RPC 服务响应相关，较少用 |

例子：

```cpp
UFUNCTION(Exec)
void KillPlayer();
```

------

## 5.4 常用 UFUNCTION meta

| meta                                | 作用                       |
| ----------------------------------- | -------------------------- |
| `DisplayName="xxx"`                 | 蓝图节点显示名             |
| `CompactNodeTitle="xxx"`            | 紧凑节点标题               |
| `Keywords="xxx"`                    | 蓝图搜索关键词             |
| `WorldContext="WorldContextObject"` | 指定世界上下文参数         |
| `DefaultToSelf="ParamName"`         | 参数默认使用 Self          |
| `HidePin="ParamName"`               | 隐藏某个引脚               |
| `AdvancedDisplay="Param1,Param2"`   | 参数放入高级展开项         |
| `AutoCreateRefTerm="Param"`         | 自动创建引用参数           |
| `DeterminesOutputType="Param"`      | 根据输入参数决定输出类型   |
| `ExpandEnumAsExecs="Param"`         | 枚举参数展开为多个执行引脚 |
| `Latent`                            | 标记潜在异步节点           |
| `LatentInfo="LatentInfo"`           | 指定 LatentInfo 参数       |
| `DeprecatedFunction`                | 标记函数废弃               |
| `DeprecationMessage="xxx"`          | 废弃提示                   |
| `UnsafeDuringActorConstruction`     | 构造 Actor 时不安全        |

例子：

```cpp
UFUNCTION(BlueprintCallable, meta=(DisplayName="造成伤害", Keywords="Damage Attack Hit"))
void ApplyDamage(float Damage);
```

# 7. 最常用组合

## 7.1 普通蓝图可编辑变量

```cpp
UPROPERTY(EditAnywhere, BlueprintReadWrite, Category="Stats")
float Health = 100.f;
```

含义：

```text
编辑器可编辑
蓝图可读写
显示在 Stats 分类
```

------

## 7.2 只读组件指针

```cpp
UPROPERTY(VisibleAnywhere, BlueprintReadOnly, Category="Components")
TObjectPtr<UStaticMeshComponent> MeshComp;
```

含义：

```text
编辑器可见但不能修改
蓝图只能读取
适合组件引用
```

------

## 7.3 蓝图可调用函数

```cpp
UFUNCTION(BlueprintCallable, Category="Combat")
void Attack();
```

含义：

```text
可以在蓝图事件图中作为节点调用
```

------

## 7.4 蓝图纯函数

```cpp
UFUNCTION(BlueprintPure, Category="Stats")
float GetHealthPercent() const;
```

含义：

```text
无执行引脚
适合返回查询结果
不应该修改对象状态
```

------

## 7.5 网络复制变量

```cpp
UPROPERTY(ReplicatedUsing=OnRep_Health)
float Health;

UFUNCTION()
void OnRep_Health();
```

含义：

```text
Health 从服务器复制到客户端
客户端收到新值后调用 OnRep_Health
```

------

## 7.6 蓝图事件

```cpp
UFUNCTION(BlueprintImplementableEvent)
void OnDeath();
```

含义：

```text
C++ 只声明
具体逻辑在蓝图中实现
```

------

## 7.7 C++ 默认实现 + 蓝图可重写

```cpp
UFUNCTION(BlueprintNativeEvent)
void Interact();
```

对应 `.cpp`：

```cpp
void AMyActor::Interact_Implementation()
{
    // C++ 默认逻辑
}
```

# 8. 说明符和 meta 的区别

这点很重要。

## 普通说明符

例如：

```cpp
UPROPERTY(EditAnywhere, BlueprintReadWrite)
float Health;
```

`EditAnywhere`、`BlueprintReadWrite` 是普通说明符，它们会影响属性在反射系统中的核心行为。

------

## Metadata 元数据

例如：

```cpp
UPROPERTY(EditAnywhere, meta=(ClampMin="0", ClampMax="100"))
float Health;
```

`ClampMin`、`ClampMax` 是元数据，更多影响编辑器显示、蓝图节点表现、输入限制等。

官方文档明确说明：Metadata 主要控制类、接口、结构体、枚举、函数或属性与引擎/编辑器的交互方式，并且 Metadata 只存在于编辑器中，不应依赖它写游戏逻辑。([Epic Games Developers](https://dev.epicgames.com/documentation/unreal-engine/metadata-specifiers-in-unreal-engine?utm_source=chatgpt.com))

# 10. 一个综合例子

```cpp
UCLASS(Blueprintable, BlueprintType)
class MYGAME_API ABaseCharacter : public ACharacter
{
    GENERATED_BODY()

public:
    UPROPERTY(VisibleAnywhere, BlueprintReadOnly, Category="Components")
    TObjectPtr<USkeletalMeshComponent> CharacterMesh;

    UPROPERTY(EditAnywhere, BlueprintReadWrite, Category="Stats",
              meta=(ClampMin="0", ClampMax="100"))
    float Health = 100.f;

    UPROPERTY(ReplicatedUsing=OnRep_Health)
    float ReplicatedHealth;

    UFUNCTION(BlueprintCallable, Category="Combat")
    void Attack();

    UFUNCTION(BlueprintPure, Category="Stats")
    float GetHealthPercent() const;

    UFUNCTION(BlueprintImplementableEvent, Category="Events")
    void OnDeath();

    UFUNCTION(Server, Reliable)
    void ServerAttack();

    UFUNCTION()
    void OnRep_Health();
};
```

这个类中：

```cpp
UCLASS(Blueprintable, BlueprintType)
```

让类可以被蓝图继承和作为蓝图变量类型。

```cpp
UPROPERTY(EditAnywhere, BlueprintReadWrite)
```

让属性能在编辑器编辑，也能在蓝图读写。

```cpp
UPROPERTY(ReplicatedUsing=OnRep_Health)
```

让属性网络复制，并在客户端收到更新后调用 `OnRep_Health`。

```cpp
UFUNCTION(BlueprintCallable)
```

让函数可以作为蓝图节点调用。

```cpp
UFUNCTION(Server, Reliable)
```

声明服务器 RPC。

------

一句话总结：

> UE5 的反射说明符就是写在 `UCLASS / USTRUCT / UENUM / UPROPERTY / UFUNCTION` 这些宏里的关键字，用来告诉引擎：这个类、属性、函数、枚举、结构体应该如何被编辑器、蓝图、GC、序列化、网络复制等系统识别和处理。
